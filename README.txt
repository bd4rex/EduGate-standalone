EduGate 单机课堂便携版

【开始上课】
1. 双击 EduGate-Standalone.exe。
2. 浏览器会自动打开教师控制台并在本机自动进入。
3. 首次使用时，在“系统 -> 上游模型 API 管理”中填写供应商接口和 Key，点击“保存接口配置”，再获取并导入模型。下次打开自动恢复。
4. 在“控制”页点击“开始课堂”，再复制本次教室电脑上的链接发给学生。

【下课】
继续使用教师端时点击“结束课堂”。准备拔走 U 盘时，点击“结束课堂并退出”（系统页为“保存并退出”）。程序会等待资料处理和记录写入结束，再关闭后台。Windows 会在 EXE 进程完全退出后显示确认窗口；看到确认后，使用 Windows 安全弹出 U 盘。关闭网页或网页停止响应不代表保存完成。若显示失败，不要直接拔盘，请检查 data/launcher.log。

【复制到另一台电脑】
必须复制整个 EduGate-Standalone 文件夹。配置、模型密钥、知识库和课堂记录保存在 EXE 旁的 config、data 文件夹中，复制后可继续使用。不要只复制 EXE，也不要删除 _internal（含浏览器 Python 离线资源）。新版本不再提供 runtime\python 学生解释器。

【固定接口与网页接入】
系统页默认展开运行状态，其余设置点击标题展开。下游 API Key 保存在 data\secrets.json，可显示、隐藏或复制；新生成的 Key 为 25 字符，已有 Key 不自动更换。调用示例默认折叠，现成客户端只需填写地址、模型和 Key。
教学网页默认推荐通过 EduGate 上传发布，复制嵌入代码和课堂分发地址即可；课堂开放后才可调用。仅在网页放在其他网站时，才需按外部网站说明配置跨域来源，嵌入代码已包含工具脚本。

【学生 Python】
Python 在学生浏览器内执行，教师电脑不执行学生代码。Demo 提供运行、停止和输出；自制教学网页可用 EduGate.runPython()，外部网页可用 EduGateClient.runPython()。默认只提供标准库，无需公网下载；上报记录不是可信判分结果。旧 /run_python 接口已停用（鉴权后返回 410）。

【知识库文件夹】
“资源”页可为每个知识库打开教师电脑上的固定文件夹。把 TXT、MD、PDF、DOCX、PPTX 或 HTML 资料放入后点击“扫描同步”，系统会添加新文件、更新变更文件并清理已删除文件的索引。默认 general 知识库不可删除。
本版内置中文语义模型与混合检索，首次启动会准备本地模型文件。给资料标注教材版本、学期与章节，再设置本节课的范围；学生 Demo 页可查看答案来源。扫描 PDF 和图片需要先做 OCR，上传后请检查解析预览。

【课堂黑名单】
在“资源”页的“课堂黑名单”中，每行填写一个禁答话题，可用 | 分隔别名，然后保存。规则对所有课堂场景和下游 AI 接口生效。开启后会检查问题、追问、答案及来源，检查失败时不作答；回答须检查完成后才显示，因此等待会比普通流式回答更长。可随时修改词条或关闭开关。

【密码】
教师电脑默认自动进入控制台。初始账号 admin，初始密码 edugate，密码配置位于 config\edugate.env。学生电脑不能使用本机自动登录。

【网络】
首次运行若 Windows 防火墙询问，请允许“专用网络”，否则学生可能无法通过局域网连接。默认使用 8000 端口；端口被占用时 EduGate 会自动换用后续可用端口。

若多网卡或 VPN 导致链接地址不适用，在“系统 -> 高级设置 -> 学生入口 IP”选择实际局域网地址，保存并重启；此项不改变教师管理权限。

English summary: double-click EduGate-Standalone.exe, start and end student access in the browser teacher console, stop the service before moving the folder, and always copy the complete folder so config and data remain available.


【便携目录隔离】
每个便携目录独立运行。同一目录重复双击只打开自己的课堂；另一位老师的程序正在运行时，将选择其他可用端口。首次运行不会自动导入教室电脑里的旧 EduGate 资料。需要迁移旧资料时，请使用“备份与恢复”。盘符和目录名可以变化；不要把 config 或 data 做成指向其他位置的目录链接。

【升级保留数据】
下载新版 EduGate-Standalone-版本-windows-x64.zip。在当前教师网页“系统 -> 程序升级”选择该 ZIP，点击“校验并升级程序”。程序会结束课堂、保存并退出，仅替换 EXE、_internal、README.txt 和 package.json，然后重新启动。config、data、账号、密钥、教材和记录保留；旧程序保留在 data/updates 下的 previous 目录。替换失败会尝试回滚原程序，并在 data/last-upgrade.json 中记录结果。升级期间不要拔盘。不要把数据备份 ZIP 当作程序升级包，也不要手工解压覆盖正在使用的目录。
首次使用可以把新版 ZIP 解压到一个新文件夹。运行环境和知识库检索模型已经包含在包内，无需现场安装 Python 或下载依赖；AI 问答仍需能够访问教师配置的模型接口。

【换电脑后的网络】
旧的固定 IP 若不属于当前电脑，会临时回退到自动选网卡，不覆盖保存的偏好。每次以当前控制页入口为准。受管理的教室电脑可能需要学校管理员预先配置局域网防火墙许可；程序不会关闭防火墙或修改系统安全策略。
