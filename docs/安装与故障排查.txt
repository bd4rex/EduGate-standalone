EduGate 单机课堂版：安装与故障排查
====================================

一、首次安装

1. 安装 64 位 Python 3.9 或更高版本。
2. 安装 Python 时勾选“Add python.exe to PATH”。
3. 双击 desktop\install_backend_deps.bat。
4. 安装脚本只使用清华 PyPI 镜像：
   https://pypi.tuna.tsinghua.edu.cn/simple
5. 脚本会创建独立环境：
   %LOCALAPPDATA%\EduGate\venv
6. 安装成功后双击 desktop\run_standalone.bat。

不要使用管理员身份安装，也不需要执行 pip install --user。EduGate 不修改系统 Python 的包。

二、首次打开

1. 启动器会打开 http://127.0.0.1:8000/admin.html。
2. 页面显示“首次运行”时，创建至少 10 个字符的管理员密码。
3. 系统没有默认密码，也不会从 .env 自动创建固定管理员。
4. 进入“配置 -> 模型与供应商管理”。
5. 填写模型 ID、显示名称、OpenAI-compatible Base URL 和 API Key。
6. 保存后点击“测试连接”。连接成功后再用于课堂。

三、Windows 防火墙

学生电脑访问教师电脑时，Windows 可能第一次弹出网络访问提示。只允许“专用网络”即可，不建议在公共网络放行。

EduGate 只需要 TCP 8000 端口。教师端和学生端不再使用 8080，也不需要 CORS 配置。

四、安装失败

“找不到 Python”
  重新安装 Python，并勾选 Add python.exe to PATH。关闭旧命令窗口后重试。

“无法访问清华源”
  在浏览器打开 https://pypi.tuna.tsinghua.edu.cn/simple 检查网络。校园网有认证页面时，先完成网页认证。脚本失败后可直接重跑，不会删除已有数据。

“创建虚拟环境失败”
  安装脚本会自动识别 Python 3.9 在含空格用户目录中的 venv 启动器问题，并从清华源安装隔离的 virtualenv 兼容引导。若两种方式都失败，请在命令行执行：py -3 -m ensurepip --upgrade，然后重跑安装脚本。

五、启动失败

“端口 8000 已被占用”
  关闭其他 EduGate、Uvicorn 或占用 8000 端口的程序，再重新启动。可用以下命令查看：
  netstat -ano | findstr :8000

“缺少后端依赖”
  确认是通过 desktop\run_standalone.bat 启动，不要直接双击 Python 文件。重新运行安装脚本修复独立环境。

仍无法启动
  查看 %LOCALAPPDATA%\EduGate\launcher.log。该文件记录启动和服务线程异常，不记录师生对话正文。

六、学生无法打开

1. 教师电脑和学生电脑应处于同一个可信局域网。
2. 使用启动器或教师控制台复制的完整课堂链接，不能只复制 student.html。
3. 确认 Windows 防火墙允许 EduGate/Python 访问专用网络。
4. 点击“换一个链接”后，旧课堂链接会立即失效，需要重新发送。
5. 不要把 127.0.0.1 地址发给学生；应使用启动器显示的局域网 IP 地址。

七、模型连接失败

1. Base URL 通常类似 https://api.deepseek.com/v1，也可填写完整的 /chat/completions 地址。
2. API Key 更新后应重新保存并点击“测试连接”。
3. 供应商必须兼容 OpenAI Chat Completions；测试会实际请求其 /models 接口。
4. secrets.json 只能由创建它的 Windows 用户解密。换电脑或换 Windows 用户后需重新填写 API Key。

八、数据与重装

所有运行数据位于 %LOCALAPPDATA%\EduGate。重装程序不会删除这里的数据。需要完全重置时，先停止 EduGate，再自行备份并删除该目录；此操作会永久删除账号、知识库和加密密钥。
