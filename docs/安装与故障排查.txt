EduGate 单机课堂版：安装与故障排查

一、推荐方式：使用打包版

1. 将完整的 EduGate-Standalone 文件夹复制到教师电脑本地磁盘。
2. 文件夹路径尽量简短，例如 D:\EduGate-Standalone；不要只复制 EduGate-Standalone.exe。
3. 双击 EduGate-Standalone.exe。打包版已包含后端依赖和学生代码所需的独立 Python，不需要安装 Python，也不需要联网安装。
4. Windows 防火墙首次询问时允许“专用网络”，否则本机能打开但学生电脑可能无法连接。
5. 浏览器自动打开教师控制台并在本机自动进入。首次使用只需添加并测试模型公司 API。

初始账号是 admin，初始密码是 edugate，保存在 config\edugate.env。正常上课由本机自动进入，无需输入密码；来自局域网的学生设备不能调用自动登录接口。

二、从源码运行（仅开发或未拿到打包版时）

1. 安装 64 位 Python 3.9 或更高版本，并勾选 Add python.exe to PATH。
2. 双击 desktop\install_backend_deps.bat。
3. 脚本固定从 https://pypi.tuna.tsinghua.edu.cn/simple 安装依赖。
4. 虚拟环境创建在项目目录 runtime\venv，不修改系统 Python 包。
5. 安装完成后双击 desktop\run_standalone.bat。

若运行启动脚本时尚未安装依赖，脚本会自动打开上述安装流程。已下载依赖、config 和 data 不会因重复安装而删除。

三、便携目录与旧版迁移

首次启动会在 EXE 或项目根目录创建：

  config\edugate.env
  data\edugate.sqlite3
  data\knowledge.sqlite3
  data\knowledge_files\
  data\runtime_config.json
  data\secrets.json
  data\launcher.log

复制整个文件夹即可保留配置、API Key、知识库、账号和课堂记录。便携版 secrets.json 不绑定 Windows 用户，因此可以在另一台电脑继续读取；同时也意味着拥有文件夹的人可以读取本地密钥。

从旧版首次升级且新 data 为空时，启动器会尝试把 %LOCALAPPDATA%\EduGate 中的数据库、知识库、配置和密钥复制到新目录，并写入 data\.imported-from-localappdata 标记。旧 DPAPI 密钥应先在原 Windows 用户下启动一次完成转换。

四、常见问题

双击后没有页面
  等待 10 秒后再试；检查 data\launcher.log。也可在浏览器打开 http://127.0.0.1:8000/admin.html。若 8000 被占用，启动器会自动尝试后续 19 个端口，日志会记录实际地址。

自动进入失败
  展开的登录区可使用 config\edugate.env 中 ADMIN_USERNAME 和 ADMIN_PASSWORD 登录。确认页面地址是 127.0.0.1 或 localhost；通过局域网 IP 打开教师页不会自动登录。

学生打不开课堂链接
  先确认学生与教师电脑在可互访的局域网；使用控制台复制的完整链接，不要手写端口或只复制 student.html。检查 Windows 防火墙是否允许 EduGate 在专用网络通信，学校网络是否启用了客户端隔离。

模型连接失败
  检查 Base URL 是否包含供应商要求的 /v1，模型 ID 是否正确，API Key 是否有效，教师电脑是否能访问供应商。点击“测试连接”会实际请求供应商模型列表。

Python 代码无法运行
  打包目录必须保留 runtime\python。源码模式需保留 runtime\venv。高级设置中的 PYTHON_RUNNER_ENABLED 应为 true；并发数范围 1 到 8。

复制后缺少配置
  必须在停止服务后复制整个文件夹，并确认 config、data、runtime、_internal 都在。只复制 EXE 不构成完整程序。

杀毒软件拦截
  one-directory 包含 Python DLL 和大量小文件。请从可信发布页重新下载完整包，必要时将整个 EduGate-Standalone 文件夹加入单位允许列表，不要单独恢复未知来源文件。

五、停止、备份与重置

“结束课堂”只关闭学生入口，教师服务仍继续运行。需要复制、移动或拔出磁盘时，请到“系统”页点击“停止服务”；服务退出时会完成数据库 checkpoint。强制结束进程通常可由 SQLite WAL 恢复，但不适合作为日常关闭方式。

“系统”页可下载完整备份并恢复。恢复会验证 ZIP，在服务停止后替换数据并重启。

完全重置：先停止 EduGate，备份整个文件夹，然后删除 config 和 data。下次启动会回到默认配置；此操作会删除账号、知识库、课堂记录和密钥。
