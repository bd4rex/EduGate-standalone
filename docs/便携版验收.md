## 本次实现

1. 数据与配置绑定便携目录；打包版忽略教室电脑遗留的数据路径、接口密钥等环境变量。
2. 持久实例 ID、每次运行 ID、操作系统目录锁；重复启动只复用本目录，其他老师使用独立端口。启动期间持有端口，避免同时启动竞争。
3. 不再自动导入宿主电脑的旧资料；浏览器会话按实例隔离，知识库选择以当前服务为准。
4. 换目录和中文路径可用；失效的固定入口 IP 临时回退自动网卡选择。随包模型会进行文件校验和按需修复，不在课堂启动时在线下载。
5. “结束课堂并退出/保存并退出”停止接收新写入，结束课堂并等待队列、资料作业和数据库 checkpoint。系统辅助程序等 EXE 进程退出并核对保存回执后才确认完成。
6. 网页程序升级：上传 ZIP，验证产品、平台、文件大小和 SHA-256，拒绝用户数据、路径越界及重名文件；保存退出后仅替换四个程序入口，保留 config/data，保存原程序并在替换失败时回滚。
7. 构建产物写入新 release 目录，不清空已有便携程序目录；中文和英文说明已同步。

## 验证结果

- 全量非 E2E 回归：**271 passed, 2 skipped, 7 deselected**，94.46 秒。2 项平台相关跳过；7 项现有 Playwright E2E 未在本轮执行。
- 该回归命令自身的后端语句/分支综合覆盖率：**85.97%**，通过 85% 门槛。
- 源码真实进程验收 10 项通过；另完成实际离线模型加载、查询和迁移检查。AI 生成使用本地模拟供应商，无真实付费模型请求。
- 最新实际 EXE 验收 **13 项通过**，运行环境 PATH 排除 Python，未设置 PYTHONHOME/PYTHONPATH。离线嵌入运行时成功加载。
- EXE 升级实测验证了真实的文件替换、退出、重启和资料保留；升级包为本次 2.3.0 产物，对同版进行替换演练，不代表未来任意版本的数据库迁移已验证。
- 注入文件占用故障：原程序回滚、教师文件保持、失败不会误报成功；保存失败回执和进程未退出时不会产生可拔盘确认。
- 浏览器打开实际 EXE 教师页，确认升级后的提示词、知识库文件和新退出/升级入口存在；截图保存于验收 artifacts。
- 测试结束后通过正式退出接口关闭测试实例；保存回执与运行 ID 匹配、监听端口关闭。原来的 8000 服务仍返回健康。

实际 EXE 检查项：

1. cold launch from a Chinese path and unrelated working directory
2. foreign machine data and credentials are not imported
3. stale LAN IP is not advertised on the new computer
4. offline embedding runtime loads from the package without Python on PATH
5. double-click reuses only the same portable instance
6. two teachers use different ports and identities
7. student streaming response reaches DONE
8. another teacher cannot see the lesson or knowledge files
9. shutdown is confirmed after process exit and queued records flush
10. folder/drive-style relocation keeps identity and credentials
11. relocation preserves knowledge, page, policy and records
12. offline upgrade replaces program and saves previous program
13. upgrade preserves teacher key, lesson, files and classroom history

## 明确未验证的边界

- 这是当前 Windows 电脑上的目录迁移、独立实例和隔离数据验证，未在第二台物理教室电脑、真实可移除 U 盘、不同 Windows/CPU 版本上验收。
- 未进行真实学生多机并发、学校防火墙/网段隔离、异常拔盘或突然断电实验。
- Windows 完成通知使用相同辅助程序，自动化验收通过无弹窗模式核对其结果；没有视觉验证原生完成弹窗。
- 网页大文件上传的自动化验证未完成：内置浏览器在文件选择后无响应；Chrome 扩展未启用文件 URL 访问权限。没有修改这些权限，也没有绕过限制。完整真实升级已经通过 multipart HTTP 与 EXE 进程验收；不能将其说成浏览器上传端到端通过。
- 浏览器退出确认框也遇到自动化调试接口阻塞，因此最后通过正式 API 完成退出。已验证网页按钮可触发确认框，但不声称网页确认到退出的完整自动化链通过。
- macOS 未重新打包；已有 macOS 结构保留，本次交付是 Windows x64。
