# 教师端界面与操作规范

四个主选项卡保持同一套蓝白样式。公共样式集中在 `frontend/assets/admin-theme.css`，页面分组在 `admin-workspaces.js`。

## 页面布局

| 主选项卡 | 布局与分组 |
| --- | --- |
| 控制 | 保留课堂控制、学生入口和 AI 设置在左、教学策略在右的工作区。 |
| 记录 | 上方紧凑统计；左侧课次列表，右侧筛选与内容。长记录在内容面板内滚动。 |
| 资源 | 二级选项卡：资料管理、课堂范围、黑名单与试问。三页沿用同一双栏比例。范围页左侧选资料、右侧筛选；黑名单页左侧编辑规则、右侧统一试问。 |
| 系统 | 二级选项卡：运行状态、模型服务、网页发布、接入配置、高级设置、运行日志、备份与升级。一次显示一组设置；模型编辑与已导入模型并排展示。 |

## 统一尺度

- 正文和表单 14px，说明文字 13px，卡片标题 18px。
- 常规按钮与输入框高 40px，紧凑行内操作 36px；触摸设备扩大点击区域。
- 普通卡片圆角 12px、内边距 20px；卡片间距 20px，表单组间距 16px。
- 蓝色表示主要操作，边框按钮表示次要操作，红色表示删除、撤销入口或退出等需要谨慎执行的操作。
- 代码与 Python 输出使用等宽字体；其他文字使用统一界面字体。
- 窄窗口通过换行或切换为单栏适配，不缩小到难以阅读的字号。
- 资源与系统工作区的标题行至少 40px，使有操作按钮和无操作按钮的卡片标题保持同一基线。
- 文件选择框外高与相邻输入框保持 40px；内部按钮扣除边框，避免控件被撑高。
- 控制页的两组下拉框使用同宽操作列，刷新按钮贴齐对应控件；记录页刷新按钮不随统计行拉伸。
- 主导航吸顶，二级导航读取其实际高度并紧接下方，适配缩放和边框；试问按钮在生成前后保持稳定宽度，折叠的长问题标题单行省略。
- 备份与升级卡片按文件、执行按钮、说明的顺序对齐；备份下载放在标题栏。高级设置勾选项与相邻输入框保持同一中心线。

## 操作约定

- 主选项卡与二级选项卡均支持左右方向键、Home、End，并有明确焦点。
- 切换子页只隐藏内容，不销毁输入；后台刷新不覆盖未保存的教学策略。
- AI 开关、模型与知识库选择立即生效；教学要求、风格、长度及回答依据保存后生效。
- 教学策略显示未保存/保存中/已保存状态；保存时防止重复提交，并保留保存期间继续输入的新内容。
- 资源子页打开时刷新状态；系统后台状态轮询只在相关状态/日志子页中执行。
- 完整试问使用已保存的模型、教学策略、课堂范围与黑名单；未保存时提示处理位置并暂停试问。结果区分提问检查、资料依据和最终回答检查，显示实际回答与引用，并支持追问和新一轮试问。检索对照保留在单独的默认折叠区。
- 范围与黑名单草稿跨子页保留；保存期间禁用相关字段，刷新或关闭页面时提示尚未保存的修改。
- 学生地址摘要用于识别当前入口，请使用复制完整链接或二维码分发。
- “已加入”统计有效学生会话，不作为实时在线连接检测。
