# EduGate v2.4.1

2026-10-26 发布的 Windows x64 维护版本，补齐“控制、记录、资源、系统”四个主页面及二级页面的视觉对齐。完整 AI 试问、便携数据隔离、安全退出与升级流程沿用 2.4.0。

## 界面与交互

- 卡片标题行统一高度；输入框、下拉框与文件选择框使用 40px 主控件高度，同行按钮居中。
- 控制页模型和知识库选择框右边缘、刷新按钮与图标对齐；记录页刷新按钮不再随统计行拉高。
- 备份下载位于卡片标题右侧；备份恢复与程序升级按“选择文件 → 执行”并排对齐。
- 主导航固定在顶部，二级导航跟随主导航实际高度，窄窗口换行后也不会重叠或留下空隙。
- 试问显示模型名称，生成与追问按钮保持宽度；长提问折叠显示一行，展开后仍保留完整内容。
- 高级设置复选框与同行输入框对齐，数据库维护选项使用中文名称。

## 安装和升级

下载 `EduGate-Standalone-2.4.1-windows-x64.zip`，解压完整文件夹后双击 EXE。已有 2.3.x / 2.4.0 便携版先备份，再在“系统 → 备份与升级”选择程序 ZIP；保留当前文件夹中的配置、密钥与课堂资料。具体步骤见[便携运行与升级](../便携运行与升级.md)。

ZIP：261195951 字节，1863 个程序文件，不含教师配置、密钥、课堂数据或演示资料。

SHA-256：`28cacb9a007f428c0b3e7e54941054618f4f0e0abf5dcdafb64110bb79bbcc0d`。

历史 2.3.0、2.3.1、2.3.2 与 2.4.0 发行包保持原样；[过程归档](../history/releases-2.3-to-2.4.md)提供原包、代码差异及历史运行源码还原的核验边界。

## 验证

本地非 E2E 回归 280 项通过，覆盖率 86.20%。12 个页面完成截图检查；重点页面完成 1024、768、480px 窗口宽度检查，无横向溢出。实际 2.4.1 EXE 的前端文件与源码一致，完整试问、黑名单拦截、学生记录隔离以及保存退出均通过检查。试问流程使用隔离数据和本地模拟上游；不代表真实教材问答准确率。

详细结果见[视觉检查记录](../ui/2026-10-26-visual-alignment.md)与[便携版验收](../便携版验收.md)。本次没有新的 macOS 二进制包，也没有在第二台物理教室电脑或真实 U 盘上复测。
