# EduGate v2.4.0

本次发布 Windows x64 便携版，采用完整文件夹、一个 EXE 启动、网页操作。

## 完整 AI 试问

“资源 → 黑名单与试问”现在可以直接生成学生会收到的最终回答，复用学生回答处理流程，使用已保存的模型、教学提示、回答风格、长度、资料范围和全局黑名单。提问检查、资料依据、最终回答检查和引用分别展示；支持连续追问与“新一轮试问”。

教师无需先开始课堂。试问不会开启学生入口，也不写入学生课堂记录；请求日志单独标记为 `/admin/classroom/trial`。未保存的范围、黑名单或教学策略会阻止试问，修改设置会清空当前试问上下文。检索对照仍保留在折叠区域，仅用于检查资料。

## 从上一公开版本累计更新

- 便携目录隔离、重复启动识别、端口冲突处理和可迁移数据；不会自动导入教室电脑中其他老师的旧资料。
- 保存并安全退出，确认进程结束后再提示拔盘；程序升级保留 config/data 并保存旧程序副本。
- 本地中文混合检索、教材版本和章节范围、解析预览、教师/学生资料隔离与引用核验。
- 全局课堂黑名单覆盖直接词、别名、追问、生成回答和引用，检查不可用时不放行。
- 控制、记录、资源、系统统一组件样式，资源和系统使用二级选项卡；记录详情可独立滚动。

## Windows 使用与升级

1. 下载 Windows x64 ZIP，解压完整 `EduGate-Standalone` 文件夹，双击其中的 EXE。不要只复制 EXE。
2. 已有 2.3.x 便携版可在“系统 → 备份与升级”选择本次程序 ZIP；升级保留当前 config/data。先备份课堂资料。
3. 没有程序升级入口的旧版，先在原程序备份，保留原文件夹，再解压新版本并用备份恢复；核对模型、资料与课堂记录后再迁移日常入口。
4. 换电脑携带整个文件夹。离开教室前使用“结束课堂并退出”，等待完成提示后安全弹出 U 盘。

发布 ZIP 只含程序与依赖，不含教师数据、密钥或演示课堂。附带 SHA256SUMS.txt。macOS 源码继续维护，本次未发布新的 macOS 二进制包。
