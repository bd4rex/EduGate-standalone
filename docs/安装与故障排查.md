# 安装与故障排查

## 打包版

打包版支持 64 位 Windows，包含后端依赖及学生浏览器使用的离线 Pyodide/WASM，不需要预装 Python。学生代码不再使用教师电脑上的独立 Python 解释器。解压完整目录后双击 `EduGate-Standalone.exe`，不要单独移动 EXE。

默认端口为 `8000`；若被占用，启动器会尝试后续端口，并打开实际地址。配置、数据库、知识库和日志位于 EXE 旁的 `config`、`data` 目录。

macOS Apple Silicon 版打开 `EduGate.app`，数据单独位于 `~/Library/Application Support/EduGate`；浏览器 Python 与 Windows 版相同。系统要求、签名和首次启动说明见 [Mac 安装说明](../desktop/MACOS-README.txt)。

## 源码版

要求 64 位 Python 3.10 或更高版本。推荐直接运行：

```text
desktop\install_backend_deps.bat
desktop\run_standalone.bat
```

安装脚本使用清华 PyPI 镜像，并在 `runtime\venv` 创建独立环境。

手动开发启动：

```powershell
python -m pip install -r backend\requirements-dev.txt
$env:EDUGATE_DATA_DIR="$PWD\.local-data"
python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

若需要学生设备访问，启动地址必须监听局域网接口；正式课堂请使用启动器提供的默认配置，而不是只监听 `127.0.0.1` 的开发命令。

## 常见问题

### 学生打不开课堂链接

1. 确认教师已点击“开始课堂”，并复制完整链接。
2. 确认两台设备在同一局域网，学生访问的是教师电脑局域网 IP，不是 `127.0.0.1`。
3. 在教师电脑防火墙中允许 EduGate 当前端口的专用网络入站访问。
4. 检查学校网络是否启用了客户端隔离；启用时学生设备无法直接访问教师电脑。
5. “结束课堂”后固定链接会暂时不可用，再次开始课堂后恢复；只有点击“换一个链接”才会永久淘汰旧链接。

### 链接显示 VPN 地址或选错了网卡

自动选择会排除已识别的 VPN/TUN、虚拟和断开连接的网卡。多网卡或特殊网卡名称无法准确识别时，在“系统 → 高级设置 → 学生入口 IP”选择或填写 `LAN_ADVERTISE_IP`，保存并重启；留空恢复自动选择。它只影响链接和嵌入代码中的地址，不改变教师权限或防火墙。

### 浏览器 Python 无法运行

- 先开始课堂，并确认高级设置允许学生浏览器运行 Python。
- 完整保留 `_internal/frontend/assets/vendor/pyodide`（源码为 `frontend/assets/vendor/pyodide`）；首次加载从教师电脑下载这些资源，不访问公网 CDN。
- 使用支持 WebAssembly 和模块 Worker 的现代浏览器；Chromium 有自动化验证，iPad Safari 仍需真机验收。
- 默认只提供标准库，暂无 pip 和交互式输入；无限循环会超时停止，刷新页面可清理本地执行环境。
- 收到 410 表示仍在调用已移除的服务端接口，需迁移到 `EduGateClient.runPython()` 或托管网页的 `EduGate.runPython()`。

### 学生能打开页面但不能提问

- 检查课堂仍在进行、AI 开关已打开、当前模型已配置 API Key。
- 查看教师端“系统”页的请求日志和模型状态。
- 若提示排队或限流，检查并发和每分钟请求上限。

### 局域网电脑打不开教师端

这是默认安全行为。单机版默认只允许教师本机访问管理端。确需使用平板管理时，在教师本机的高级设置中：

1. 启用 `ALLOW_LAN_ADMIN`。
2. 在 `ADMIN_ALLOWED_IPS` 填写平板当前的精确 IP；多个地址用英文逗号分隔。
3. 给平板设置 DHCP 地址保留，保存并重启 EduGate。
4. 在平板打开 `http://教师电脑IP:端口/admin.html`，仍使用教师账号登录。

只启用开关但白名单为空不会开放任何局域网设备。IP 白名单不是密码，局域网 HTTP 也没有 TLS；只应在可信隔离网络使用。详细说明见 [架构与安全边界](架构与安全边界.md)。

### 端口冲突或服务未启动

- 查看 `data\launcher.log`。
- 在“系统”页确认实际端口和运行状态。
- 使用源码模式时，确认 `runtime\venv` 已成功创建且 Python 版本不低于 3.10。

### 复制后模型密钥丢失

必须复制完整目录，包括 `data\secrets.json`。便携密钥可迁移但保护较弱，切勿把完整目录上传到公开网盘或代码仓库。

### 复制或备份后数据库异常

复制前先在“系统”页点击“停止服务”。运行中直接复制 SQLite 文件可能遗漏 WAL 中尚未合并的数据。

知识库旧绝对路径在升级时转换为当前目录内的相对路径。若提示无法安全迁移或路径包含链接，请保留原文件，从有效完整备份恢复并检查索引；不要放宽路径检查或把原目录做成 junction 来绕过。
