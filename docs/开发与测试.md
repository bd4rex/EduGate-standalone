# 开发与测试

## 环境基线

- 64 位 Python 3.10+
- Windows 为主要运行与打包平台
- FastAPI + Uvicorn + SQLite
- 原生 HTML/CSS/JavaScript 教师端与学生端

## 后端模块

| 模块 | 职责 |
| --- | --- |
| `app/main.py` | 创建应用、中间件、路由注册、OpenAPI 和静态页面挂载 |
| `app/state.py` | 生命周期和共享服务实例 |
| `app/dependencies.py` | 教师、课堂和平台访问校验 |
| `app/chat_service.py` | 模型选择、知识检索、普通与流式对话 |
| `app/runtime_config.py` | 模型目录和默认课堂场景持久化 |
| `app/schemas.py` | 请求与响应模型 |
| `app/routers/` | 按 auth、chat、classroom、config、knowledge、models、python、system 分组的 API |
| `app/core.py` | 旧导入路径的兼容门面；新代码不应继续向其中堆功能 |

## 运行测试

从仓库根目录运行：

```powershell
python -m pytest -q -p no:cacheprovider -m "not e2e" --basetemp=.pytest-tmp --cov=backend/app --cov-branch --cov-report=term --cov-fail-under=85
python -m compileall -q backend\app
```

CI 在 Python 3.10 和 3.12 上执行快速回归，并要求后端语句/分支综合覆盖率不低于 85%；另在 Python 3.12 上用 Chromium 执行真实浏览器课堂仿真。测试覆盖单教师认证、局域网教师边界、学生会话、课堂令牌轮换、模型供应商、知识库、课堂记录、备份恢复、Python 任务池、静态分发契约和流式请求。详细边界见[测试覆盖与仿真审计](测试覆盖与仿真审计.md)。

首次运行浏览器 E2E 需要安装 Chromium：

```powershell
python -m playwright install chromium
$env:RUN_BROWSER_E2E = "1"
python -m pytest -q -p no:cacheprovider -c pytest.ini -m e2e --basetemp=.pytest-e2e-tmp
```

`test_model_concurrency_is_bounded` 使用 64 个并发任务验证模型并发限制器；它是确定性回归测试，不应被解读为特定电脑上的吞吐量承诺。正式部署容量取决于模型供应商延迟、教师电脑、网络和课堂请求模式，应在目标教室做试课。

## 打包

```text
desktop\build_windows.bat
```

脚本先验证 Python 3.10+，再生成 `dist\EduGate-Standalone`。发布前至少完成：

1. 全量测试通过。
2. 打包目录在一台无开发环境的 Windows 电脑上启动成功。
3. 教师本机能进入管理端，局域网学生不能进入管理端。
4. 两台局域网设备能通过课堂链接加入、提问并在换链后失效。
5. 停止服务后完成一次备份与恢复演练。

## 兼容与迁移

保留启动器中的旧数据迁移逻辑，是为了升级现有便携目录；这不等于继续保留旧的多教师 API。`runtime_config.json` 中历史 `teacher_policies` 会迁移到唯一的 `default` 场景，保存后不再写回旧字段。
