# 开发与测试

## 环境基线

- 64 位 Python 3.10+
- Windows 与 macOS Apple Silicon 运行和打包；两端均使用学生浏览器 Python
- FastAPI + Uvicorn + SQLite
- 原生 HTML/CSS/JavaScript 教师端与学生端

## 后端模块

| 模块 | 职责 |
| --- | --- |
| `app/main.py` | 创建应用、中间件、路由注册、OpenAPI 和静态页面挂载 |
| `app/state.py` | 生命周期和共享服务实例 |
| `app/dependencies.py` | 教师、课堂和平台访问校验 |
| `app/chat_service.py` | 模型选择、知识检索、普通与流式对话 |
| `app/classroom_tasks.py` | 绑定课次，撤销排队/流式任务，释放上游连接 |
| `app/network.py` | 枚举已连接网卡，选择或覆盖学生入口 IP |
| `app/runtime_config.py` | 模型目录和默认课堂场景持久化 |
| `app/published_pages.py` | 教学网页校验、存储、活动入口和资源白名单 |
| `app/schemas.py` | 请求与响应模型 |
| `app/routers/` | 按 auth、chat、classroom、config、knowledge、models、publishing、python、system 分组的 API |
| `app/core.py` | 旧导入路径的兼容门面；新代码不应继续向其中堆功能 |

## 运行测试

从仓库根目录运行：

```powershell
python -m pytest -q -p no:cacheprovider -m "not e2e" --basetemp=.pytest-tmp --cov=backend/app --cov-branch --cov-report=term --cov-fail-under=85
python -m compileall -q backend\app
```

CI 在 Python 3.10 和 3.12 上执行快速回归，并要求后端语句/分支综合覆盖率不低于 85%；另在 Python 3.12 上用 Chromium 执行真实浏览器课堂仿真。测试覆盖单教师认证、局域网教师边界、学生会话和课次撤销、模型供应商、知识库复制/迁移安全、教学网页发布与备份、课堂记录、密钥禁用、浏览器 Python、静态分发契约和流式请求。详细边界见[测试覆盖与仿真审计](测试覆盖与仿真审计.md)。

首次运行浏览器 E2E 需要安装 Chromium：

CI 另在 macOS 上运行快速回归和编译检查；DPAPI 专属用例只在 Windows 上执行，macOS 使用便携密钥存储并验证文件权限。

```powershell
python -m playwright install chromium
$env:RUN_BROWSER_E2E = "1"
python -m pytest -q -p no:cacheprovider -c pytest.ini -m e2e --basetemp=.pytest-e2e-tmp
```

`test_model_concurrency_is_bounded` 使用 64 个并发任务验证模型并发限制器；它是确定性回归测试，不应被解读为特定电脑上的吞吐量承诺。正式部署容量取决于模型供应商延迟、教师电脑、网络和课堂请求模式，应在目标教室做试课。

## 打包

学生 Python 使用 `frontend/assets/edugate-python.js` 和 `python-sandbox.js`，运行环境固定在 `assets/vendor/pyodide/`，具体版本、来源与校验值见该目录的 README。WASM 中的 Python 3.14.2 与后端 Python 3.10+ 是两个独立环境。升级资源时同步固定版本和哈希，并运行真实浏览器测试；课堂不能依赖公网 CDN。

```text
desktop\build_windows.bat
```

脚本先验证 Python 3.10+，在 `dist/releases/版本-时间/` 中生成完整便携目录、文件校验清单和程序升级 ZIP，不覆盖已有目录。

打包会收录完整前端（包含离线 WASM）以及后端 `psutil` 网卡枚举依赖，不再生成 `runtime/python` 学生解释器。构建新版本时输出到新目录，不覆盖正在使用的数据目录。

可让同一组浏览器测试运行刚构建的 EXE；夹具会使用临时配置/数据目录，禁用旧数据导入和自动打开浏览器，不读取真实模型密钥：

```powershell
$env:RUN_BROWSER_E2E = "1"
$env:EDUGATE_TEST_EXECUTABLE = (Resolve-Path "dist/EduGate-Standalone/EduGate-Standalone.exe").Path
python -m pytest backend/tests/e2e -q
Remove-Item Env:EDUGATE_TEST_EXECUTABLE
```

程序发布验证至少包括：

1. 全量测试通过。
2. 使用隔离配置启动真实 Windows EXE，核对打包文件、完整回答、引用和安全退出。
3. 教师与学生权限隔离测试通过；教师试问不改变学生课堂状态或记录。
4. 备份、恢复、程序升级与失败回滚的自动化或隔离进程演练，保留具体版本和结果。
5. 发布目录不包含教师配置、密钥、课堂数据或测试档案；为 ZIP 生成 SHA-256。

教室部署验收另在无开发环境的 Windows 电脑、真实 U 盘和两台局域网设备上检查启动、加入、提问、换链、网络与备份恢复。发布记录必须区分已执行的软件测试和未执行的物理环境验收。

完整教师试问的回归在 `test_teacher_trial.py`：覆盖管理鉴权、拒绝策略覆盖、与学生处理流程一致、课前调用、记录隔离、已保存范围、严格依据、提问/回答黑名单、追问、模型失败及 AI 开关。浏览器 E2E 覆盖生成、追问、重置和课堂记录不被污染。

## 兼容与迁移

便携启动不再自动导入教室电脑中的旧数据。迁移资料使用明确的备份恢复操作，程序升级只替换程序文件。`runtime_config.json` 中历史 `teacher_policies` 会迁移到唯一的 `default` 场景，保存后不再写回旧字段。


## U 盘运行与保留数据升级

日常只需双击完整便携目录内的 EXE。换电脑时携带整个文件夹；“结束课堂并退出”会保存并关闭后台，Windows 在进程完全退出后给出确认。程序升级在“系统 → 程序升级”选择发布 ZIP，保留 config、data，并保存原程序副本。详细流程、目录隔离和验证边界见 [便携运行与升级](便携运行与升级.md)。
