EduGate 单机课堂版技术说明

一、产品边界

本版本面向一位教师在上课期间临时启动，不是学校级长期服务。教师电脑同时承担 Web 后端、静态页面、配置数据库、知识库和受控 Python 执行节点；学生只通过局域网课堂链接访问。

二、教师端形态

教师端只有 Web 控制台。无窗口启动器负责启动、监督、重启、停止、端口选择和离线恢复。教师本机通过仅接受 loopback 请求的 /auth/local-session 自动进入管理员会话；远程学生设备不能使用该接口。用户名和初始密码仍位于 config\edugate.env，作为兜底。

三、便携目录

APP_DIR 是打包 EXE 所在目录或源码项目根目录。默认路径为：

  APP_DIR\config\edugate.env
  APP_DIR\data\...
  APP_DIR\runtime\python\python.exe（打包版）
  APP_DIR\runtime\venv\Scripts\python.exe（源码版）

所有课堂状态随文件夹复制。SQLite 在停止服务时执行 WAL checkpoint。备份使用 SQLite 在线快照，并把配置、运行策略、便携密钥和知识文件写入 ZIP；恢复包先验证，随后由监督进程离线替换。

四、模型密钥

便携模式使用 portable-plain-v1 secrets.json，以满足跨 Windows 用户和跨电脑复制。页面不回显 API Key，但该格式不提供操作系统级加密。旧版 DPAPI 文件在原 Windows 用户下首次迁入时转换为便携格式。

五、学生身份与并发

学生打开课堂链接后静默接入，无需填写姓名、电脑名或座位号。浏览器在本地生成并保存稳定设备标识，教师端据此生成设备标签并记录请求 IP；每次课堂仍使用独立 student_session_id 维持会话。聊天和 Python 限流按学生会话计算，不依赖教师 IP，也不会因共享反向代理 IP 让全班共用预算。浏览器还会为同一课堂保留本地多轮历史。

Python 使用 4 个默认独立槽位和 64 个候位任务的受控队列，可配置到 8 路。队列不缓存结果；每个任务启动新的受限子进程并继承最小环境变量集。打包版携带独立标准库解释器，避免把 PyInstaller EXE 误当 Python。

六、升级兼容

新 data 为空时，启动器会一次性尝试导入 %LOCALAPPDATA%\EduGate 的旧数据库、配置、知识文件和密钥。已有便携数据时不会覆盖。可设置 EDUGATE_SKIP_LEGACY_IMPORT=true 禁止自动导入。

七、构建

desktop\build_windows.bat 固定使用清华 PyPI 源，生成 one-directory 包并添加 runtime\python。one-directory 便于检查、增量升级和防病毒扫描，也能让 config、data 以清晰的相对目录长期保留。
