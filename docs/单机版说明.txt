EduGate 单机课堂版说明
=====================

定位
----

本版本面向一位教师和一台教师电脑，不依赖学校级账号中心、集中数据库或独立 LiteLLM。教师电脑同时承担控制台、学生页面、本地策略、知识库和上游模型代理。

运行结构
--------

浏览器/学生设备
    -> 无窗口监督进程
       -> 教师电脑 Uvicorn :8000
       -> 身份、课堂令牌、限流、教师策略
       -> 本地 SQLite 知识库检索
       -> OpenAI-compatible 模型公司 API

教师端、学生端和 API 同源运行，因此局域网使用不依赖 CORS。可选的 CORS_ORIGINS 只用于确有需要的第三方网页集成。

教师端只有 Web 界面。后台监督进程没有 Windows 窗口，负责启动、重启、停止和恢复前的离线数据替换；所有操作入口集中在教师 Web 控制台。

身份与访问边界
------------

1. 管理员首次初始化只允许从教师电脑回环地址执行。
2. 不存在固定 ADMIN_API_KEY 或默认管理员密码。
3. 教师会话是内存中的随机令牌，带过期时间，可主动注销和按用户失效。
4. 学生先用每次启动随机生成的课堂令牌换取匿名学生会话；新版页面按学生会话限流，旧接口仍可按来源 IP 兼容访问。
5. 平台兼容接口必须显式配置 PLATFORM_API_KEY，否则返回 503。

数据与密钥
----------

运行数据位于 %LOCALAPPDATA%\EduGate。模型 API Key 使用 Windows DPAPI 加密，runtime_config.json 只保存 credential_id。配置文件采用临时文件、fsync 和原子替换，SQLite 使用 WAL 和 busy timeout。

Web 控制台可生成 SQLite 一致性快照备份。恢复包先验证并暂存，随后由监督进程在服务退出、数据库无连接时替换文件并重新启动。

资源边界
--------

模型请求有超时和最大并发；流式回答有读取超时与心跳；上传有字节和 PDF 页数限制；日志有保留上限；Python 运行器默认关闭，启用后有学生会话、AST 限制、超时、内存限制和单并发。Python 子进程使用环境变量白名单，打包程序需要独立 Python 解释器。

升级与打包
----------

源码启动使用 %LOCALAPPDATA%\EduGate\venv。Windows 打包使用 desktop\edugate_standalone.spec 生成 one-directory 程序。程序资源与运行数据分离，更新程序目录不应覆盖课堂数据。
