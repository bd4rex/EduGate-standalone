# EduGate 单机课堂版使用手册

## 课前准备

1. 双击 `EduGate-Standalone.exe`；源码模式双击 `desktop\run_standalone.bat`。
2. 教师控制台会在本机浏览器打开。便携版默认只允许教师电脑访问管理端。
3. 在“系统 → 上游模型 API 管理”添加供应商，填写 API 地址和密钥，获取并导入模型。
4. 在“控制”页选择模型，设置系统提示词、回答长度、随机性和知识库。
5. 在“资源”页上传资料，或打开知识库目录后执行“扫描同步”。
6. 正式教学时，在“系统”页最下方的“教学网页发布”上传单个 HTML 或含 `index.html` 的 ZIP；未发布时学生入口使用内置 Demo 测试页。

便携版初始账号为 `admin`，初始密码为 `edugate`。本机自动进入教师控制台时通常无需输入；首次使用后仍建议修改密码。

## 把课堂分发给学生

1. 教师电脑和学生设备连接同一个可信局域网。
2. 登录后先复制固定课堂链接。链接会跨课次和程序重启保持不变，可以提前嵌入 PPT、网页课件或班级平台。
3. 确认控制页显示的是本节课需要的发布网页；上课时点击“开始课堂”，再通过班级群、教学平台、投屏或内置二维码发送完整入口。
4. 学生在浏览器中打开链接后自动加入，无需填写姓名、电脑名或座位号。
5. 下课点击“结束课堂”；当前学生会话立即撤销、固定链接暂停，但教师控制台继续运行。下一次点击“开始课堂”后，同一链接恢复可用并建立新的课堂记录批次。
6. 只有链接泄露或确需撤销旧课件入口时才点击“换一个链接”；旧链接和已经换取的学生会话会永久失效，所有嵌入位置都需要更新。

同一内容教三个班时可以复用同一活动网页和链接；每个班上课前点击“开始课堂”、下课后点击“结束课堂”，记录仍按课次分开。控制页同时提供复制链接和二维码。二维码包含持久课堂令牌，不要公开发布。

内置 IP 地址学习单只作为 **Demo 测试页**。课堂未开始时，Demo 和已发布网页都不能加入课堂或调用 AI；正式教学建议在系统页发布教师自己的网页。网页发布、切换和 `EduGate.ask()` 流式调用详见 [教学网页发布](教学网页发布.md)。

## 学生会话如何工作

- 课堂链接把高熵 `class_token` 放在 URL 片段（`#`）中，页面请求本身不会把它发送到服务器日志。
- `class_token` 保存在教师电脑密钥存储中；开始、结束课堂或重启程序都不会轮换它。
- 学生页用课堂令牌调用 `/classroom/join`，换取该浏览器独立的 `student_token`。
- 后续 AI 对话和 Python 请求使用学生令牌，不共享教师会话。
- 浏览器本地保存稳定设备标识，教师端据此生成设备标签，并记录请求 IP。
- 每台浏览器独立限流；全班共用同一出口 IP 时也不会共用一个学生会话。
- 学生页本地最多保存最近 50 条消息，发送给模型时只带最近 10 条。

## 接入下游客户端和教学网页

“系统 → 下游接口与网页嵌入”提供两个可复制入口：

- 后端客户端：生成独立平台密钥，复制 `/v1` Base URL、虚拟模型 `edugate` 和 OpenAI SDK 示例。平台密钥不得放进网页。
- 教学网页：复制 `EduGateClient` 嵌入代码。代码中的持久课堂令牌只会换取学生会话，受课堂启停、换链撤销和每学生限流约束。
- 托管网页：在“系统 → 教学网页发布”上传后，由控制页入口自动分发；网页在隔离沙箱中通过 `EduGate.ask()` 获得流式回答，不接触课堂令牌、教师会话或平台密钥。

外部教学网页还需在高级设置填写准确的 `CORS_ORIGINS` 并重启服务。同源页面无需配置。完整说明见 [下游接口与网页嵌入](下游接口与网页嵌入.md)。

## 课堂记录

“记录”页按课堂显示自动设备标签、请求 IP、AI 对话和 Python 运行结果。记录只写入教师电脑，默认保留 30 天，可在高级设置中关闭或调整保留期。

不要把自动设备标签理解为学生实名。若学校需要实名或座位映射，应另行设计告知、采集和最小化保存方案。

## Python 执行

Python 改为在学生浏览器内执行，不在教师电脑启动学生代码进程。打开 Demo 中的“Python 练习”，输入代码后点击“运行 Python”，可查看实时输出或点击停止。每个页面同一时间运行一个任务，每次使用全新解释器；默认执行超时 3 秒、代码上限 6000 字符，均可在高级设置调整。

所需 Pyodide/WASM 和标准库随程序提供，课堂使用不依赖公网下载。默认不支持 pip、任意外网请求或交互式 `input()`。教师端记录会标明“学生浏览器上报，未经服务端验证”；下课后的结果不能写入下一节课。托管课件可调用 `EduGate.runPython()`，示例见[下游接口与网页嵌入](下游接口与网页嵌入.md)。

“系统”页显示 Python 执行位置，不再显示教师端线程/队列。高级设置中的输入在状态自动刷新和手动刷新时会保留；编辑完成后仍需点击保存，注明需重启的设置在重启后生效。

若系统显示的是 VPN 地址或有多个教室网卡，在高级设置“学生入口 IP”中选择实际局域网地址，保存并重启。该选择不会允许学生设备访问教师管理端。

## 下课、备份与迁移

- “结束课堂”暂停学生入口并撤销当前学生会话，但保留固定链接；再次开始课堂后原链接恢复。
- 要退出程序、复制或移动整个目录，请在“系统”页点击“停止服务”，等待数据库完成写入。
- 迁移时复制完整 `EduGate-Standalone` 文件夹，不要只复制 EXE；`data\published_pages` 中的教学网页也会一并迁移。
- “下载完整备份”包含账号、策略、知识库、教学网页、活动入口索引和密钥。
- 便携版 `data\secrets.json` 可随文件夹迁移，但不绑定 Windows 用户；持有完整目录的人可能读取其中的模型密钥，请按敏感教学资料管理。
