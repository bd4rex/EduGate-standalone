# EduGate 单机课堂版使用手册

## 课前准备

1. 双击 `EduGate-Standalone.exe`；源码模式双击 `desktop\run_standalone.bat`。
2. 教师控制台会在本机浏览器打开。便携版默认只允许教师电脑访问管理端。
3. 在“系统 → 上游模型 API 管理”添加供应商，填写 API 地址和密钥，获取并导入模型。
4. 在“控制”页选择模型，设置系统提示词、回答长度、随机性和知识库。
5. 在“资源”页上传资料，或打开知识库目录后执行“扫描同步”。

便携版初始账号为 `admin`，初始密码为 `edugate`。本机自动进入教师控制台时通常无需输入；首次使用后仍建议修改密码。

## 把课堂分发给学生

1. 教师电脑和学生设备连接同一个可信局域网。
2. 在“控制”页底部点击“开始课堂”。
3. 点击“复制链接”，通过班级群、教学平台或投屏发送完整链接。
4. 学生在浏览器中打开链接后自动加入，无需填写姓名、电脑名或座位号。
5. 若链接误发，点击“换一个链接”；旧链接和已经换取的学生会话会立即失效。
6. 下课点击“结束课堂”；学生入口关闭，但教师控制台继续运行。

当前版本提供复制链接，尚未内置二维码。需要扫码时，可把课堂链接粘贴到学校认可的二维码工具中；不要使用会公开收集链接的在线服务，因为链接中的课堂令牌等同于临时入场凭证。

## 学生会话如何工作

- 课堂链接把高熵 `class_token` 放在 URL 片段（`#`）中，页面请求本身不会把它发送到服务器日志。
- 学生页用课堂令牌调用 `/classroom/join`，换取该浏览器独立的 `student_token`。
- 后续 AI 对话和 Python 请求使用学生令牌，不共享教师会话。
- 浏览器本地保存稳定设备标识，教师端据此生成设备标签，并记录请求 IP。
- 每台浏览器独立限流；全班共用同一出口 IP 时也不会共用一个学生会话。
- 学生页本地最多保存最近 50 条消息，发送给模型时只带最近 10 条。

## 课堂记录

“记录”页按课堂显示自动设备标签、请求 IP、AI 对话和 Python 运行结果。记录只写入教师电脑，默认保留 30 天，可在高级设置中关闭或调整保留期。

不要把自动设备标签理解为学生实名。若学校需要实名或座位映射，应另行设计告知、采集和最小化保存方案。

## Python 执行

Python 执行器默认有 4 个并发槽位和最多 64 个排队任务。每次运行都会启动新的受限子进程，不共享变量或解释器状态。同一学生同一时间只能有一个排队或运行任务。

## 下课、备份与迁移

- “结束课堂”只撤销学生入口。
- 要退出程序、复制或移动整个目录，请在“系统”页点击“停止服务”，等待数据库完成写入。
- 迁移时复制完整 `EduGate-Standalone` 文件夹，不要只复制 EXE。
- 便携版 `data\secrets.json` 可随文件夹迁移，但不绑定 Windows 用户；持有完整目录的人可能读取其中的模型密钥，请按敏感教学资料管理。
