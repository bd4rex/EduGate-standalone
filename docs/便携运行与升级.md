# U 盘便携运行与程序升级

适用：Windows 64 位便携版，单教师课堂。交付为完整文件夹，教师只需双击 `EduGate-Standalone.exe`，其余操作在网页完成。

## 开课与携带

1. 将发布 ZIP 解压到 U 盘上的一个新文件夹，保留 EXE、`_internal`、`README.txt`、`package.json`。
2. 双击 EXE。首次运行创建同目录的 `config`、`data`，并从随包资源准备知识库检索模型，不需要安装 Python 或在线下载运行依赖。
3. 配置模型接口、教材与教学网页，开始课堂，将当前控制页链接发给学生。
4. 下课后若继续备课，使用“结束课堂”；准备离开时使用“结束课堂并退出”。
5. 等待 Windows 的退出确认，再使用系统的“安全弹出”。浏览器关闭、断线或 HTTP 请求失败都不代表数据已保存。

AI 问答仍须能访问配置好的上游接口。学生和教室电脑须能在局域网互访；Windows 防火墙、网段隔离和学校设备管理策略可能需要管理员事先配置。本程序不自动关闭防火墙或改变系统安全策略。

## 换电脑与教师隔离

- Windows 打包版的数据根目录由 EXE 所在目录决定，不接受教室电脑遗留的环境变量将配置、数据库、模型密钥或资料路径改到其他位置。测试工具可用显式 `--portable-dir` 指定隔离目录。
- 每份数据有持久实例标识；每次运行另有随机运行标识。同目录使用操作系统文件锁，进程崩溃后锁由系统释放。
- 重复双击仅复用同一目录的运行实例。另一目录正在占用端口时选择其他端口，不连接它的教师页。
- 不自动导入 `%LOCALAPPDATA%/EduGate`。从历史版本迁移资料应先在旧程序导出备份，再在自己的新便携目录恢复。
- 教师浏览器会话按实例和服务地址隔离，并验证运行标识。挂载的知识库以当前服务配置为准，不把旧浏览器选择自动写回。
- 换盘符或中文目录名可以继续使用。不得将 `config`、`data` 或关键数据文件做成指向其他位置的链接。
- 换电脑后，如保存的入口 IP 不属于本机，当前运行会回退到自动选网卡；配置中的偏好不被覆盖。以本次控制台显示的链接为准。

`data/secrets.json` 为便携格式，不依赖原 Windows 账号。U 盘包含模型密钥与课堂记录，请作为教师个人资料保管。此版本没有新增密码加密保险箱。

## 退出确认的边界

“保存并退出”会停止接受新的写入请求，结束课堂、撤销学生会话和进行中的课堂任务，等待资料处理与记录队列，检查数据库写入结果并完成 checkpoint。

Windows 自带 PowerShell 在电脑的临时目录中等待 EXE 进程真正退出，再核对这次运行的保存结果和目录锁。只有两者都通过，才显示完成提示；保存失败或另一实例已启动时不会声称可拔盘。电脑策略若阻止辅助程序启动，退出请求会报错，当前服务保持运行。

该辅助程序不携带 API 密钥，不从 U 盘运行额外的解释器，也不需要安装 PowerShell 或更改执行策略。后台索引较慢时需要等待；请勿用强制结束进程代替保存。

## 在网页中升级，保留数据

1. 下载可信来源的 `EduGate-Standalone-版本-windows-x64.zip`。
2. 在当前教师页打开“系统 → 备份与升级 · 保留课堂资料”。
3. 选择升级 ZIP，点击“校验并升级程序”。这会结束当前课堂。
4. 等待校验、保存、退出、替换程序和重新启动；整个过程中保持 U 盘连接。

升级包包含每个程序文件的 SHA-256、大小、产品和平台标识。服务拒绝篡改、缺失、越界、重名文件，以及试图携带 `config` 或 `data` 的升级包。哈希用于完整性校验，不是发布者数字签名。

只允许替换 `EduGate-Standalone.exe`、`_internal`、`README.txt`、`package.json`。`config` 和 `data` 不作为替换目标；原程序移到 `data/updates/*-previous` 保留。文件替换失败时尝试回滚，结果记在 `data/last-upgrade.json`。若电脑断电导致升级被打断，可在确认程序没有运行后，将 previous 目录的程序文件恢复到便携目录，保留现有 `config`、`data`。

程序升级 ZIP 和课堂数据备份 ZIP 用途不同。旧版尚无升级入口时：停止旧程序，把新版解压到新目录，再复制旧目录的完整 `config`、`data` 到新目录，验证资料后保留原目录作为备份。不要覆盖正在运行的目录。

## 构建与可复现验收

`desktop/build_windows.bat` 安装构建依赖并准备固定版本的检索模型，调用 `desktop/build_portable_release.py`。每次输出到新的 `dist/releases/版本-时间/`，不会清空现有便携目录。

```powershell
.venv-build\Scripts\python.exe desktop\verify_portable.py
.venv-build\Scripts\python.exe desktop\verify_portable.py --package "完整便携包目录" --upgrade "程序升级ZIP"
```

验收脚本使用独立目录和本地模拟模型，不读真实教师密钥。它验证中文路径、重复启动、两位教师共存、错误环境变量隔离、过期入口 IP、流式问答完成、保存退出、目录迁移和升级后的资料保留。测试证据在 `artifacts/portable-acceptance-时间/results.json`。

这些是本机模拟换目录和换运行实例的验证。另一台实际教室电脑、不同 Windows 版本、U 盘性能、学校防火墙和真实学生终端仍须现场验收。
