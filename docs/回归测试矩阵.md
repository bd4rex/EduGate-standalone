# EduGate 单机版回归测试矩阵

本文档记录开发过程中实际出现过或讨论确认过的风险，确保后续修改不会重新引入这些问题。

## 自动化测试

| 风险 | 回归目标 | 自动化用例 |
|---|---|---|
| 教师端同时出现 Windows 窗口和 Web 控制台 | 主启动器不依赖 Tkinter，打包为无控制台程序，脚本使用 `pythonw` | `test_teacher_launcher_is_web_only_and_windowless` |
| 教师安装网络受限 | 安装与打包脚本固定使用清华 PyPI 源 | `test_teacher_install_and_build_scripts_use_tsinghua_mirror` |
| 目标端口被其他服务占用 | 只有带 EduGate 标识的健康响应才会被启动器识别 | `test_healthcheck_requires_edugate_identity_header` |
| Web 重启后会话失效并重复报错 | 系统操作必须由受控启动器调度，旧教师会话按设计失效 | `test_system_management_requires_supervised_launcher`、`test_logout_revokes_session` |
| 备份恢复覆盖任意文件 | 拒绝路径穿越、未知条目和非法 ZIP，只在重启前暂存 | `test_restore_rejects_unsafe_or_unknown_entries`、`test_pending_restore_rejects_path_traversal` |
| 恢复后知识库文件与配置不一致 | 离线恢复替换配置和知识库目录并清理暂存包 | `test_pending_restore_replaces_configuration_and_knowledge` |
| 模型或知识库仍被课堂引用时被删除 | 返回 409，保留正在使用的资源 | `test_referenced_model_and_knowledge_source_cannot_be_deleted` |
| 64 名学生请求突破模型并发上限 | 64 个模拟请求必须受信号量约束 | `test_model_concurrency_is_bounded` |
| 学生经过同一代理后共享一个 IP 限流桶 | 匿名学生会话分别限流，旧课堂口令方式保持兼容 | `test_student_sessions_rate_limit_students_independently_behind_one_ip` |
| 教师轮换课堂链接后旧学生仍能访问 | 轮换课堂口令同时撤销所有旧学生会话 | `test_classroom_rotation_invalidates_student_session` |
| 学生刷新页面丢失多轮历史 | 历史写入本地存储，恢复时校验结构，只发送最近 10 条 | `test_student_page_persists_history_and_uses_anonymous_session` |
| Python 子进程读取模型密钥 | 子进程只继承最小环境变量白名单 | `test_python_runner_does_not_inherit_application_secrets` |
| 打包 EXE 把自身误当作 Python 解释器 | 打包态要求独立解释器，不可用时返回明确 503 | `test_frozen_bundle_requires_a_separate_python_executable`、`test_python_runner_unavailable_is_reported_as_503` |
| DeepSeek 默认模型名退役 | 默认值使用当前 `deepseek-v4-flash` | `test_current_deepseek_default_is_not_retired_alias` |
| 普通教师看到系统管理页 | 系统标签和视图保持管理员专属 | `test_system_view_remains_admin_only` |
| 发布后品牌图标或双语文档入口丢失 | Web、Windows 打包和中英文文档保持统一品牌资源及双向链接 | `test_brand_assets_are_used_by_docs_web_and_windows_bundle`、`test_chinese_and_english_project_docs_link_to_each_other` |

## 每次发布的人工验证

1. 在全新的 Windows 用户目录运行首次安装脚本，确认所有依赖均从清华源安装。
2. 双击启动脚本和打包 EXE，确认没有持续存在的命令行或桌面控制窗口。
3. 完成首次管理员设置、模型 API 探测、学生链接访问、流式回答、停止生成和课堂口令轮换。
4. 用两个浏览器配置文件模拟同一代理下的学生，确认两者获得不同的 `student_session_id`。
5. 连续刷新学生页，确认当前课堂历史恢复；轮换课堂链接后确认新课堂不会加载旧历史。
6. 运行 64 客户端、24 至 32 上游并发的 30 分钟压测，观察 429、首字延迟、内存和 SQLite 锁等待。
7. 下载备份，新增配置和知识库文件后执行恢复，确认重启后回到备份状态。
8. 在启用 Python 执行器前配置独立解释器，验证基础代码、禁止导入、超时、输出截断和无窗口运行。

## 本地执行

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r backend\requirements-dev.txt
python -m pytest -q --basetemp=.pytest-tmp
python -m compileall -q backend desktop
```

GitHub Actions 在 Windows 的 Python 3.9 和 3.12 上执行同一组测试。
