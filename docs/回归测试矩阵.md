## 自动化测试

| 风险 | 回归目标 | 自动化用例 |
|---|---|---|
| 教师端同时出现 Windows 窗口和 Web 控制台 | 主启动器不依赖 Tkinter，打包为无控制台程序，脚本使用 `pythonw` | `test_teacher_launcher_is_web_only_and_windowless` |
| 教师安装网络受限 | 安装与打包脚本固定使用清华 PyPI 源 | `test_teacher_install_and_build_scripts_use_tsinghua_mirror` |
| 配置和数据写入 Windows 用户目录，复制文件夹后丢失课堂状态 | 默认使用 EXE 旁的 `config`、`data` 和 `runtime`，并在关机时 checkpoint | `test_windows_bundle_is_a_copyable_portable_classroom_folder`、`test_pending_restore_replaces_configuration_and_knowledge` |
| API Key 绑定原 Windows 用户，换电脑后无法使用 | 便携密钥格式随完整文件夹复制并可在新路径读取 | `test_portable_secret_store_survives_copying_the_folder` |
| 老师每次上课都要寻找密码和登录 | 仅 loopback 可换取本机教师会话，局域网学生请求被拒绝 | `test_portable_local_session_opens_teacher_console_without_password`、`test_portable_local_session_is_rejected_for_student_devices` |
| 单教师课堂仍显示学校式用户管理 | 教师 Web 控制台移除多教师账号与密码维护入口，并突出品牌 Logo | `test_portable_teacher_console_omits_multi_teacher_management_and_uses_prominent_branding` |

| 目标端口被其他服务占用 | 只有带 EduGate 标识的健康响应才会被启动器识别 | `test_healthcheck_requires_edugate_identity_header` |

| 删除旧默认模型后重启又自动恢复 | 旧版默认配置只迁移一次，完成标记随便携配置保存 | `test_completed_runtime_migration_does_not_restore_legacy_default` |

## 每次发布的人工验证

1. 在全新的 Windows 用户目录运行首次安装脚本，确认所有依赖均从清华源安装。
2. 双击启动脚本和打包 EXE，确认没有持续存在的命令行或桌面控制窗口。
3. 完成首次管理员设置；配置两家含同名模型的供应商，核对供应商切换、组合标记、自动拼接地址、弹窗检索、显示名修改和批量导入，再分别选择、请求和删除其中一个模型；继续完成开始课堂、学生链接访问、流式回答、停止生成、课堂口令轮换和结束课堂，确认教师页面不会被结束课堂关闭。
4. 用两个浏览器配置文件模拟同一代理下的学生，确认两者获得不同的 `student_session_id`。
5. 连续刷新学生页，确认当前课堂历史恢复；轮换课堂链接后确认新课堂不会加载旧历史。
6. 运行 64 客户端、24 至 32 上游并发的 30 分钟压测，观察 429、首字延迟、内存和 SQLite 锁等待。
7. 下载备份，新增配置和知识库文件后执行恢复，确认重启后回到备份状态。
8. 使用打包目录自带的 `runtime\python`，验证 4–8 路并发、队列满、同学生重复任务、实时输出、禁止导入、超时、输出截断和无窗口运行。
9. 学生打开课堂链接时确认不出现身份输入框；分别以普通教师和管理员打开“记录”页，确认教师权限隔离、自动设备标签/IP 筛选、AI/Python 类型筛选、课堂轮换归档和删除操作。
10. 使用 iPad Safari 或对应的 768×1024、1024×768 触控视口检查顶部课堂按钮、四个标签、表单、开关和学生入口，确认无重叠或横向滚动。
11. 在“系统”页确认运行时间位于标题右侧，复制局域网地址并打开程序目录；确认系统日志位于高级设置上方且两者初始折叠，页面不重复显示服务状态，也不显示数据目录、剩余磁盘、进程 ID 或监督模式。
12. 在“资源”页打开知识库文件夹，新增、修改和删除一个资料文件，每次点击“扫描同步”，确认索引分别新增、更新和移除；确认默认知识库明确标注不可删除。

## 本地执行

```powershell
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r backend\requirements-dev.txt
python -m pytest -q --basetemp=.pytest-tmp
python -m compileall -q backend desktop
```

GitHub Actions 在 Windows 的 Python 3.9 和 3.12 上执行同一组测试。
