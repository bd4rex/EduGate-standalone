EduGate 单机课堂便携版验收清单

一、完整包与首次启动

[ ] 64 位 Windows 电脑未安装 Python 时，完整打包目录仍可启动。
[ ] EduGate-Standalone.exe、_internal、runtime\python 和 README.txt 都在同一发布目录。
[ ] 双击 EXE 后没有持续显示的命令行或 Windows 控制窗口。
[ ] 浏览器自动打开教师 Web 控制台。
[ ] 教师本机无需输入密码即可自动进入 admin；局域网设备调用 /auth/local-session 返回拒绝。
[ ] config\edugate.env 和 data 目录在首次启动后出现在 EXE 旁。
[ ] 初始账号 admin、密码 edugate 可在自动进入失败时登录。
[ ] 8000 端口被占用时自动使用后续端口，页面和课堂链接均使用实际端口。

二、复制与迁移

[ ] 配置模型、知识库和课堂策略后停止服务，复制整个目录到另一位置仍可使用。
[ ] 复制后模型 API Key 无需重新输入，页面也不会回显完整 Key。
[ ] 数据库、课堂记录、知识文件和 config 设置都跟随目录。
[ ] 只复制 EXE 时文档有明确提示该方式不受支持。
[ ] 新 data 为空时可一次性导入旧 %LOCALAPPDATA%\EduGate 数据；已有便携数据不会被覆盖。
[ ] “结束课堂”只撤销学生链接和会话；“系统 -> 停止服务”完成 SQLite checkpoint 后目录可复制或移动。

三、教师 Web 全功能

[ ] 控制页可开关 AI、选择唯一模型、设置系统提示词、回答随机性、回答长度上限和知识库。
[ ] 控制页最下方的学生课堂入口旁可开始/结束课堂，并可复制和轮换课堂链接。
[ ] iPad 竖屏和横屏下按钮、输入框和开关适合触摸，不重叠且无需横向滚动。
[ ] “上游模型 API 管理”位于系统日志正上方并默认折叠；页面直接显示“添加供应商”，主表单保留来源名称、API Key、API URL、API 路径和“重置/获取模型”。
[ ] 每个已配置供应商分组直接显示“添加模型”，点击后获取该供应商模型并打开选择弹窗。
[ ] 获取模型后打开独立弹窗；面对大量模型可即时检索、勾选多个模型、修改显示名并批量导入，主页面只显示已导入模型。
[ ] 可切换多家已配置供应商；两家供应商存在同名模型时，目录、课堂选择、API Key、删除和实际上游请求均按“供应商 + 上游模型 ID”隔离。
[ ] 选择已有供应商后可删除整家供应商；其全部模型和 API Key 一并清理，课堂引用先切换到其他供应商模型，无替代模型时阻止删除。
[ ] 已导入模型可直接修改显示名并删除，修改显示名不会清除已有 API Key。
[ ] 删除仍被场景或教师策略引用的旧模型时，可切换到替代模型并完成删除；重启后旧模型不会重新出现。
[ ] 资源页优先显示知识库列表，可创建、编辑和删除非默认知识库，并明确标注默认知识库不可删除。
[ ] 每个知识库可打开教师电脑上的固定文件夹；扫描同步可增量添加、更新和移除 TXT/MD/PDF 等资料索引。
[ ] 单教师便携界面不显示教师账号列表、新增教师或修改密码等用户管理入口。
[ ] 记录页可按课堂、自动设备标签/IP 和 AI/Python 类型筛选，并可删除整节课堂。
[ ] 系统页可复制局域网地址，并可从“停止服务”右侧直接打开程序目录。
[ ] 全局“运行中”表示服务已连接；系统页把运行时间放在“运行状态”标题右侧。
[ ] 系统页不重复显示服务状态，也不显示数据目录、剩余磁盘、进程 ID 和监督模式；高级设置默认折叠。
[ ] 系统日志位于高级设置正上方，默认折叠，展开后可查看启动和运行日志。
[ ] 备份与恢复默认折叠，展开后两个操作按钮同排；系统页可修改高级参数、重启和停止服务。

四、学生会话与聊天

[ ] 学生必须使用教师复制的完整课堂链接进入。
[ ] 学生进入时不出现姓名、电脑名或座位号输入框；浏览器静默生成稳定设备标识，教师端自动生成设备标签并记录请求 IP。
[ ] 课堂令牌可换取独立 student_session_id，同一浏览器重复进入同一课堂保持设备关联。
[ ] 64 名学生经过同一代理时仍分别限流，而不是共享每分钟 30 次。
[ ] 同一学生刷新后可恢复最近 50 条本地消息，多轮对话保持连贯。
[ ] 每次发送模型的历史最多 10 条，防止请求无限增长。
[ ] 轮换课堂链接后旧链接和旧学生会话立即失效。
[ ] 结束课堂后旧链接和旧学生会话立即失效，但教师控制台与健康检查仍在线。

五、Python 任务池

[ ] 打包版使用 runtime\python\python.exe，不把 EduGate EXE 当作解释器。
[ ] 默认 4 路并发、64 个候位任务，可配置到 8 路。
[ ] 同一学生只能有一个排队或执行中的任务。
[ ] 队列满返回 429；排队超时、执行超时和输出截断有明确状态。
[ ] SSE 实时出现 queued、running、output、completed/error，而非结束后一次返回。
[ ] 每个任务是独立子进程，不复用变量、结果或工作目录。
[ ] 子进程不能继承模型 API Key 等应用密钥。

六、安装、文档与构建

[ ] 源码安装脚本只向项目 runtime\venv 安装，不写系统 site-packages。
[ ] 源码安装和 Windows 打包脚本都固定使用清华 PyPI 镜像。
[ ] 包内 README.txt 以中文说明启动、下课、复制、密码和防火墙。
[ ] 中文 README 为主入口并链接英文 README；英文 README 可返回中文。
[ ] pytest 全量测试通过，打包目录在一台干净 Windows 电脑完成上述手工验收。
