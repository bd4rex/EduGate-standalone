EduGate 单机课堂版验收清单
==========================

安装
----
[ ] 全新 Windows 用户可运行 desktop\install_backend_deps.bat。
[ ] 安装输出明确显示清华 PyPI 镜像。
[ ] 依赖位于 %LOCALAPPDATA%\EduGate\venv，而不是系统或用户 site-packages。
[ ] desktop\run_standalone.bat 可重复启动。
[ ] 启动后没有持续显示的 Windows 控制窗口，只打开教师 Web 控制台。

首次初始化
----------
[ ] 首次页面要求创建至少 10 个字符的管理员密码。
[ ] admin / edugate 无法登录。
[ ] 非教师电脑不能调用首次初始化接口。
[ ] 退出后原会话 token 立即失效。

模型与密钥
----------
[ ] 可添加 OpenAI-compatible Base URL、模型 ID 和 API Key。
[ ] “测试连接”会实际访问供应商并显示结果。
[ ] 页面/API 不回显 API Key。
[ ] runtime_config.json 和 secrets.json 中没有 API Key 明文。
[ ] 换 Windows 用户后要求重新填写 API Key。

课堂访问
--------
[ ] 教师控制台和学生页面都通过 8000 端口打开。
[ ] 学生完整课堂链接可从同一局域网访问。
[ ] 缺少或错误课堂令牌时 /chat 和 /chat/stream 返回 401。
[ ] 点击“换一个链接”后旧链接立即失效。
[ ] 同一代理 IP 下的两个学生获得不同匿名会话，彼此不共享限流额度。
[ ] 刷新学生页面后当前课堂多轮历史仍可恢复，更换课堂链接后不加载旧课堂历史。
[ ] 学生不能覆盖模型或 system prompt。
[ ] 频繁请求会触发 429。
[ ] 学生可停止正在生成的流式回答。

知识库与资源限制
----------------
[ ] 超过 25 MB 的默认上传被拒绝且不留残余文件。
[ ] 超过 200 页的默认 PDF 被拒绝。
[ ] PDF 解析期间健康检查和其他请求仍可响应。
[ ] 严格知识库模式按教师策略工作。

Python 与平台接口
-----------------
[ ] 默认 /run_python 返回“disabled”。
[ ] 启用后仍要求课堂令牌，import 被拒绝，死循环会超时。
[ ] 4 个默认槽位可并行执行，超过槽位的任务进入有界队列，队列满返回 429。
[ ] 同一匿名学生不能同时占用多个排队/运行任务。
[ ] /run_python/stream 在任务结束前返回 queued、running 和 stdout/stderr，最终返回 done。
[ ] Python 子进程无法继承 UPSTREAM_API_KEY 等模型密钥，且运行时不弹出控制台窗口。
[ ] 未配置 PLATFORM_API_KEY 时 /v1/chat/completions 不可用。

数据与升级
----------
[ ] 数据生成在 %LOCALAPPDATA%\EduGate。
[ ] 技术请求日志默认不含消息正文，并按 LOG_MAX_RECORDS 清理旧记录。
[ ] “记录”页按课堂展示 AI/Python 内容，普通教师只能看到自己的课堂，管理员可查看全部。
[ ] 课堂记录只显示匿名学生编号，不保存学生 IP，并按默认 30 天和总量上限清理。
[ ] 关闭 CLASSROOM_RECORDING_ENABLED 后不再新增课堂内容，按课堂删除可立即清除详情。
[ ] 更新或替换程序目录后，账号、知识库和策略仍存在。
[ ] desktop\build_windows.bat 可生成 dist\EduGate-Standalone。
[ ] “系统”页可显示监督状态、启动日志和请求统计。
[ ] Web 重启后 PID 改变、服务恢复且旧登录会话失效。
[ ] Web 停止后 8000 端口不再监听。
[ ] 可下载完整备份，并可验证、暂存、重启恢复。
