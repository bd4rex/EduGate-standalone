# 知识库与课堂黑名单

EduGate 在教师电脑上使用 LanceDB、中文分词和本地 BGE 向量模型进行混合检索。教师继续使用原有的课堂入口、模型供应商和上下课控制。课堂黑名单是全局规则，不随学生传入的场景参数改变。

## 课前准备

1. 在“系统”中配置可用的回答模型，并确认模型能完成回答。上游密钥暂停时，需要先从相应的课堂 AI 开关恢复访问。
2. 进入“资源 → 课堂范围”，查看检索状态。新打包版带有约 90 MB 的中文语义模型，首次运行会安装到本机数据目录。需要维护时展开“检索维护”，源码运行可点击“准备语义模型”，或运行下文的准备命令。
3. 上传资料，点击“解析预览”检查章节、页码和正文是否正确。原文件始终保留，可由教师下载核对。
4. 在“课堂范围”选择本节课资料并应用；在“黑名单与试问”保存禁答话题，然后统一试问。确认规则和资料合适后，再开始课堂并分发学生链接。

索引、分词和向量计算在本机进行。话题检查、资料依据判断和回答生成使用教师配置的模型服务，因此这些环节仍需要该服务可用。缺少本地向量模型时会明确显示“关键词检索”，不会把关键词结果标成语义检索。

## 资料格式与更新

- 支持 TXT、Markdown、CSV、JSON、HTML、XML、日志、文本型 PDF、DOCX 和 PPTX。
- 新安装默认单文件上限为 25 MiB，PDF 上限为 500 页；已有配置会保留，可在高级设置中调整上传和 PDF 限制。
- PDF 保留页码；PPTX 保留幻灯片编号；Word、Markdown 等保留可识别的标题和段落。Word 不推测页码。
- 表格会按行抽取文字。扫描页、图片、复杂公式的视觉信息不会自动变成可靠文字；预览会显示相应警告。此类资料应先做 OCR 并人工检查，或补充文字说明。
- 可以把资料放入知识库目录，再执行“扫描同步”。未变化文件会跳过；修改或删除会更新索引。文件解析失败时，该文件的旧索引不会继续冒充新版本用于回答。
- 后台任务会显示运行、完成或失败状态。老索引和模型版本变化会触发重建；相同模型下未变化的片段可以复用向量。

## 多班复用与课堂范围

“资料属性”可设置学科、年级、教材版本、学期，以及“学生课堂资料”或“仅教师参考”。不同班级可以复用同一份教材，通过课堂范围选择文件、版本和章节，不必复制多份全文。

“课堂范围”左侧选择知识库与文件，右侧按章节包含、学科、年级、版本和学期筛选。学科、年级、版本和学期按填写值匹配。**未勾选文件意味着使用所选库中符合其他筛选条件的全部学生资料**，不是空集合。修改后必须点击“应用到当前课堂”。

“黑名单与试问”右侧直接生成学生会收到的回答，使用已保存的模型、教学策略、课堂范围和黑名单。有未保存修改时先保存。流程包含提问检查、资料检索、严格模式的依据核对、回答生成以及回答和引用的黑名单检查；检查失败或资料不足时展示与学生相同的课堂提示。可连续追问，也可开始新一轮；上下文仅保留在当前页面，不写入学生课堂记录。可用 Ctrl/Command + Enter 发送。

下方“仅检查资料检索（对照）”保留关键词、语义与混合检索诊断，不生成回答，也不会改变完整试问的检索流程。找到片段不代表证据足以回答；最终效果应结合完整回答和引用核对。

教师参考资料不会进入学生检索。建议把参考答案单独保存成文件，并设为“仅教师参考”，不要依赖提示词隐藏同一文件中的答案。文件删除或改为教师参考后，已有的范围不会自动扩大到其他文件。

## 黑名单

在“资源 → 黑名单与试问”左侧勾选“启用禁答话题”，每行填写一项，然后保存。例如：

```text
游戏
```

可以用 `|` 添加明确别名，以便立即匹配，例如：

```text
游戏攻略|王者荣耀|原神配装
```

规则保存在本机配置中，重启后保留；教师可以修改、删除或停用。新安装的通用配置不预置禁答话题。本次用户实例按要求配置“游戏”。

机制分为几层：

1. 直接匹配词条和别名，统一大小写、全角字符、空格及常见分隔符。命中后不进入资料检索和回答生成。
2. 对换一种说法、具体名称和连续追问进行话题判断。“用于学习”“角色扮演”等说法不构成绕过规则的例外。
3. 过滤命中禁答词的检索片段，检查最终答复及将展示的资料依据。
4. 学生重新打开引用时，重新检查当前课堂、资料范围、版本和黑名单。教师仍可在管理端检查、编辑和下载原资料。

普通问答、流式问答和 `/v1/chat/completions` 都执行同一份黑名单。学生不能通过请求字段、其他场景或额外系统提示词关闭规则。

**黑名单启用时，完整内容通过检查后才展示。** 流式接口仍提供 SSE 心跳、内容和结束标记，但不会把尚未检查的模型文字先发送给学生；也不透传未检查的其他候选答复、推理字段或工具参数。话题检查不可用、结果格式异常或无法确认时，系统暂不作答。直接词条匹配很快，语义和输出检查会增加模型调用及等待时间。

语义判断依赖模型，不能保证识别所有隐晦表达，也可能误拦。教师应通过试问检查实际问题，并补充明确别名。保存规则后对新提问生效，不删除学生已经看过的历史消息。

## 严格依据与来源核对

“控制 → 仅根据课堂知识库回答”会要求资料对问题提供支持，并核对模型给出的证据摘录是否确实出现在资料中。关键词命中或“话题相关”不能代替回答依据；没有依据时给出不足提示，不使用通用知识补齐事实。

回答中使用 `[K1]` 等引用标记，学生可以点击“本次检索依据”打开相应原文。资料更新、移出课堂范围、改为教师参考或下课后，旧引用可能不再可用，需要重新提问。引用能帮助核对，但不能替代教师对整段答案是否被原文支持的判断。

“AI 可使用通用知识”允许补充说明，但仍执行黑名单，并要求区分资料依据和通用知识补充。

## 备份、迁移与回退

现有完整备份包含配置、原始资料以及 SQLite 中的片段、元数据和向量。LanceDB 检索目录是可重建缓存，不作为唯一的数据来源。模型随新安装包提供；源码环境应先准备相同的模型。备份 ZIP 不额外打包模型权重和派生检索缓存。

迁移或恢复后，程序会按数据库修订和模型标识检查索引，必要时重建。重建过程中请关注状态与文件警告。回退到不支持新配置字段的旧程序时，应恢复升级前保留的**完整旧程序与数据目录**，不要只替换 EXE。

## 开发与复现

```powershell
python -m pip install -r backend/requirements-dev.txt
python -X utf8 desktop/prepare_knowledge_model.py
python -X utf8 docs/research/evaluate_knowledge_upgrade.py --model-dir data/knowledge_models
```

本地模型固定为 `BAAI/bge-small-zh-v1.5` 的 ONNX 版本，模型清单记录不可变下载修订以及权重、分词器和配置文件哈希。打包脚本会准备并导出独立模型目录；教师运行打包版时无需下载这些模型文件。

本次 Windows 实现与验收记录见 [知识库升级验收](research/2026-10-24-knowledge-implementation.md)。开发回归集不等于真实教材准确率；正式课堂应补充教师审定的问题、版本和页码。
