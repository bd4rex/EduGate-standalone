# 教学网页发布

EduGate 可以把教师制作的网页作为正式学生课堂入口。内置 IP 地址学习单现在明确标记为 **Demo 测试页**，只用于首次联调和体验，不建议作为正式教学内容。

## 发布流程

1. 准备一个 UTF-8 编码的完整 HTML 文件，或一个包含 `index.html` 的 ZIP。
2. 打开教师端“系统”，在最后的“教学网页发布”中填写网页名称并选择文件。
3. 点击“上传并发布”。当前活动网页会立即替换控制页中的学生课堂入口；课堂令牌和固定链接机制不变。
4. 回到“控制”页，点击“开始课堂”，再复制链接或二维码发给学生。
5. 需要换课件时可保留多个已上传网页，点击“设为课堂入口”切换。切换到 Demo 不会删除已上传网页。

仓库中的 `samples/teaching-page-demo.html` 可以直接上传，用于验证发布和流式桥接。

课堂未开始或已经结束时，发布网页与 Demo 都不能加入课堂或调用 AI。再次开始课堂后，当前入口使用同一持久课堂令牌恢复。主动“重新生成入口”才会淘汰旧令牌和已有学生会话。

## 文件格式

- 单文件：`.html` 或 `.htm`，页面中的 CSS 和 JavaScript需要内嵌。
- 多文件：`.zip`，必须且只能有一个 `index.html`；它可以位于 ZIP 根目录，或位于唯一的顶层文件夹中。
- 支持的资源包括 CSS、JavaScript、JSON、文本、常见图片、字体、音频和视频。
- ZIP 中不允许额外 HTML、SVG、可执行文件、符号链接、加密内容或越界路径。最多 1000 个文件，上传大小受“单文件上传上限”控制。

示例：

```text
lesson.zip
├─ index.html
├─ app.js
├─ style.css
└─ images/
   └─ diagram.png
```

## 在发布网页中调用课堂 AI

发布页不需要保存课堂令牌，也不能获得教师会话或平台密钥。EduGate 会在隔离沙箱中注入一个受控桥接对象：

```html
<button id="ask">提问</button>
<div id="answer"></div>
<script>
document.querySelector("#ask").addEventListener("click", async () => {
  const output = document.querySelector("#answer");
  output.textContent = "";
  try {
    await EduGate.ask("请用初中生能理解的方式解释光的反射。", (delta) => {
      output.textContent += delta;
    });
  } catch (error) {
    output.textContent = error.message;
  }
});
</script>
```

也可以传入最多 20 条 `user` / `assistant` 消息：

```javascript
await EduGate.ask([
  { role: "user", content: "我认为入射角越大，反射角越小。" },
  { role: "assistant", content: "你可以先回忆反射定律。" },
  { role: "user", content: "请继续提示我，不要直接给答案。" }
], appendText);
```

`EduGate.ask()` 返回一个 Promise，完成时得到完整文本；第二个参数会逐块收到流式文本。返回的 Promise 还提供 `cancel()`，可用于停止当前生成。

## 安全边界

- 教师上传的 HTML 在无 `allow-same-origin` 的 iframe 沙箱中运行，不能读取教师控制台的存储、课堂令牌或管理接口会话。
- 受信任外层页面代为换取独立学生会话，并只接受规范的课堂消息；学生限流、课堂启停、当前教学策略和课堂记录仍由后端执行。
- 活动 HTML 文档只有在课堂开放且 `class_token` 正确时才返回。资源 URL 使用随机网页 ID，且服务端不提供上传的 HTML、SVG 或可执行资源。
- 发布网页本身仍可能包含教师编写或引入的第三方脚本。正式使用前应检查来源，不要在页面中收集不必要的学生个人信息。
- 局域网默认使用 HTTP，只应在可信、隔离的教室网络运行。

已上传网页、活动入口索引和资源保存在 `data/published_pages/`，随“下载完整备份”和便携目录一起迁移。
