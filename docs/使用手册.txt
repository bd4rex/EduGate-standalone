EduGate 单机课堂版使用手册

一、课前启动

1. 双击 EduGate-Standalone.exe；源码模式双击 desktop\run_standalone.bat。
2. 后台服务不会显示独立 Windows 控制窗口，浏览器自动打开教师 Web 控制台。
3. 教师电脑自动进入 admin 账号。初始密码 edugate 位于 config\edugate.env，仅在自动进入失败或主动关闭自动登录时使用。
4. 顶部状态显示“运行中”后即可配置课堂。若默认端口被占用，启动器会自动使用后续端口。

二、配置模型

1. 打开“系统”，在“系统日志”上方展开“上游模型 API 管理”。
2. 填写显示名称、供应商、模型 ID、OpenAI-compatible Base URL 和 API Key。
3. 点击“测试连接”，成功后保存并启用模型。
4. API Key 不会回显，保存在程序目录 data\secrets.json。复制整个文件夹后仍可继续使用。

三、配置课堂

1. 在“控制”页选择唯一启用的模型。
2. 设置系统提示词、回答随机性、回答长度上限和知识库。
3. 按需打开或关闭“允许学生使用 AI”。
4. 页面上的“当前课堂配置”是当前学生实际使用的配置。

四、管理知识库

1. 打开“资源”，知识库列表会优先显示在页面顶部。
2. “打开文件夹”会在教师电脑上打开该知识库的固定目录；即使从 iPad 点击，文件夹仍在教师电脑上打开。
3. 可把 txt、md、csv、json、html、xml、log 或 pdf 文件直接放入目录，再点击“扫描同步”。系统只重新索引新增或内容发生变化的文件，并清理已从目录删除的文件索引。
4. 默认 general 知识库可编辑、打开和扫描，但不可删除；其他未被课堂配置使用的知识库可删除。
5. “新建或编辑知识库”默认折叠；点击知识库行中的“编辑”会自动展开并填入当前资料。

五、学生进入与连续对话

1. 到“控制”页最下方的“学生课堂入口”，点击“开始课堂”。
2. 点击同一区域的“复制链接”并发给学生。
3. 每名学生用课堂令牌换取独立 student_session_id；共享代理 IP 不会让 64 人共用同一限流额度。
4. 学生同一浏览器、同一课堂下刷新页面仍保留最近 50 条本地消息，多轮对话可保持连贯。
5. 每次发送只附带最近 10 条消息，控制模型上下文长度。
6. 点击“换一个链接”会使旧链接和旧学生会话立即失效，并生成新入口。

六、Python 并发执行

Python 任务池不是缓存。请求先进入最多 64 个位置的受控队列，4 个默认工作槽位并发取任务；每个任务启动新的受限 Python 子进程。不同学生不共享变量、解释器或结果。同一学生同一时间只能有一个排队或运行任务。

/run_python/stream 会实时返回 queued、running、output、completed 或 error。可在“系统 -> 高级设置”把并发数调整到 1 到 8。

七、记录与下课

“记录”页按课堂查看学生电脑名、请求 IP、AI 对话和 Python 结果，可按电脑或类型筛选，也可删除整节课堂。学生首次进入时填写电脑名或座位号，浏览器会记住该值；记录仅保存在教师电脑，默认保留 30 天。

下课在“学生课堂入口”旁点击“结束课堂”。当前学生链接和学生会话会立即失效，但教师控制台保持运行，可继续整理记录或开始下一节课。

只有需要退出 EduGate 或复制、移动整个程序文件夹时，才到“系统”页点击“停止服务”。服务退出时会完成数据库 checkpoint，网页随后不可用是正常现象。

八、账号、配置和复制

教师本机自动进入不影响学生端边界。学生通过局域网访问不能获取教师会话。账号密码、模型策略和课堂记录位于 data 数据库，初始密码设置位于 config\edugate.env。

要换电脑或带走配置，先在“系统”页停止服务，再复制完整 EduGate-Standalone 文件夹。不要只复制 EXE。便携密钥不绑定 Windows 用户，目标电脑无需重新输入 API Key。

九、系统页

全局顶部的“运行中”表示教师页面已连接到正在运行的 EduGate 服务。系统页在“运行状态”标题右侧显示已运行时间，并提供局域网地址、Python 运行状态和请求统计；局域网地址可直接复制，“停止服务”右侧可打开程序目录。备份与恢复、上游模型 API 管理、系统日志和高级设置默认折叠，需要时再展开。修改需要重启的设置后，请使用页面中的“重启服务”。
