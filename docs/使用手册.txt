EduGate 单机课堂版使用手册
==========================

一、课前启动

1. 双击 desktop\run_standalone.bat。
2. 启动脚本会在后台运行，不显示 Windows 控制窗口。
3. 等待浏览器自动打开教师控制台。
4. 首次运行创建管理员密码；以后用该密码登录。

二、配置模型

1. 打开“资源”。
2. 在“模型与供应商管理”填写模型 ID、Base URL 和 API Key。
3. 点击“新增/更新模型”。
4. 点击“测试连接”，确认供应商能返回模型列表。
5. 返回“控制”，选择该模型。

API Key 不会回显，也不会写入 runtime_config.json。它由当前 Windows 用户的 DPAPI 加密保存在 secrets.json。

三、准备课堂策略

1. 用“允许学生使用 AI”开关控制服务。
2. 选择模型。
3. 设置 System Prompt、Temperature、Max Tokens。
4. 需要时创建知识库并上传资料。
5. 严格知识库模式下，超出资料范围的问题会被阻止或提示。
6. 点击“保存当前 AI 策略”。

上传单文件默认不超过 25 MB，PDF 默认不超过 200 页。扫描图片型 PDF 可能无法抽取文字。

四、让学生进入

1. 在“学生课堂入口”点击“复制链接”。
2. 将完整链接发给学生。
3. 链接会绑定当前教师并携带临时课堂令牌。
4. 学生页面支持流式回答和“停止生成”。
5. 怀疑链接泄露或要结束旧课堂时，点击“换一个链接”并重新发送。

课堂令牌每次重启都会更换。它放在 URL 的 # 片段中，不会写入服务器访问日志。

五、课堂结束

1. 可关闭“允许学生使用 AI”。
2. 在教师控制台点击“退出”。
3. 打开“系统”，点击“停止服务”。网页关闭后服务已经停止，再次使用需双击启动脚本。

六、账号与密码

教师登录会话默认 8 小时过期。退出、修改密码、管理员重置密码、停用或删除账号后，相关会话立即失效。

管理员可创建普通教师账号。普通教师只能管理自己的课堂策略，以及以“用户名-”开头的知识库。

七、系统管理

管理员在“系统”页可以：

1. 查看服务状态、局域网地址、进程、磁盘空间和请求统计。
2. 查看启动日志和最近请求日志。
3. 下载包含账号、策略、知识库和加密密钥的完整备份。
4. 上传备份并在离线重启阶段恢复，避免运行中覆盖 SQLite。
5. 修改端口、超时、限流、上传、日志和 Python 运行器参数。
6. 重启或停止后台服务。

修改高级设置后需要重启。修改端口时，EduGate 会在新地址打开控制台。备份中的 DPAPI 密钥只可由原 Windows 用户解密。

八、Python 课堂演示

/run_python 默认关闭。确有需要时，可在“系统 -> 高级设置”启用 Python 运行器并重启。默认有 4 个独立执行槽位和 64 个排队位置；同一学生只能有一个排队或运行任务。/run_python/stream 会实时返回 queued、running、stdout/stderr、done 事件。

即使启用，它也只适合短小基础语法演示，禁止 import/open/eval 等操作，并有时间、内存和并发限制，不能视为完整在线判题沙箱。8 核教师电脑可将 PYTHON_RUNNER_MAX_CONCURRENCY 调整到 4–8；不要通过无限增加槽位绕过 CPU 和内存边界。

九、隐私与日志

“记录”页会按课堂保存匿名学生的 AI 问答和 Python 运行内容，默认只保存在教师电脑 30 天，不保存学生 IP。教师只能查看自己的记录，管理员可以查看全部记录；可按课堂删除，也可在高级设置中关闭 CLASSROOM_RECORDING_ENABLED。

技术请求日志与课堂记录相互独立。请求日志默认不保存师生消息正文，只记录路由、模型、耗时、token 数量和错误，最多保留 5000 条；只有明确设置 LOG_MESSAGE_PREVIEW=true 时才会保存短消息预览。
