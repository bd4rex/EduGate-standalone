# 下游接口与网页嵌入

EduGate 单机版可以作为教室内的 AI 中转站，对下游提供两种用途不同的入口。两者都执行教师控制台中的当前课堂策略，包括上游模型、系统提示词、知识库和严格模式。

| 用途 | 接口 | 凭证 | 适合场景 |
| --- | --- | --- | --- |
| 后端程序、桌面客户端、服务端插件 | `GET /v1/models`、`POST /v1/chat/completions` | `Authorization: Bearer <平台密钥>` | OpenAI SDK、支持自定义 Base URL 的服务端应用 |
| 浏览器教学网页 | `POST /classroom/join`、`POST /chat/stream` | `class_token` 换取独立 `X-Student-Token` | 学习单、网页课件、校内教学平台中的流式 AI 助手 |
| EduGate 托管教学网页 | `EduGate.ask()` 沙箱桥接 | 包装页代管 `class_token`，网页本身无凭证 | 教师上传 HTML/ZIP 后直接由学生课堂入口分发 |

平台密钥权限高且没有浏览器保密能力，绝不能把平台密钥写进 HTML 或前端 JavaScript。教学网页应使用第二种流程。

## OpenAI 兼容接口

在教师端“系统 → 下游接口与网页嵌入”中：

1. 点击“生成”创建随机平台密钥，或输入自定义高熵密钥后保存。
2. 在离开页面前复制新密钥。EduGate 之后只显示已设置状态，不再回显明文。
3. 复制界面显示的 API Base URL 和调用示例。

标准配置为：

```text
Base URL: http://教师电脑IP:8000/v1
API Key:  教师端生成的平台密钥
Model:    edugate
```

`edugate` 是稳定虚拟模型。下游无需知道上游供应商的模型 ID；教师切换模型、提示词或知识库后，下游地址和模型名保持不变。非默认场景使用 `edugate:<scenario_id>`，可通过 `GET /v1/models` 获取。

Python OpenAI SDK 示例：

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://192.168.1.10:8000/v1",
    api_key="eg_替换为教师端生成的密钥",
)

stream = client.chat.completions.create(
    model="edugate",
    messages=[{"role": "user", "content": "请解释这个知识点"}],
    stream=True,
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
```

兼容接口接受 `system`、`user`、`assistant` 文本消息，以及 `temperature`、`max_tokens` 和 `stream`。调用方传入的 system 消息会叠加在教师课堂策略之后，平台调用应只授予受信任的后端应用。流式响应为 OpenAI 风格 SSE，并以 `data: [DONE]` 结束。

点击“关闭”会持久保存禁用状态；之后的下游请求会被拒绝，即使环境中仍有 `PLATFORM_API_KEY`，重启或复制目录后也不会回退启用。只有主动保存或生成密钥才能恢复。生成新密钥后旧密钥不能再用于新请求；已经发往上游的请求不保证被中止。

## 嵌入教学网页

教师端会根据当前局域网地址和持久课堂令牌生成可复制代码。示例使用随 EduGate 分发的无框架浏览器 SDK：

```html
<script src="http://192.168.1.10:8000/assets/edugate-client.js"></script>
<script>
const edugate = new EduGateClient({
  baseUrl: "http://192.168.1.10:8000",
  classToken: "替换为教师端生成代码中的课堂令牌"
});

async function askEduGate(question, appendText) {
  const messages = [{ role: "user", content: question }];
  for await (const text of edugate.streamText(messages)) {
    appendText(text);
  }
}
</script>
```

SDK 自动完成以下过程：

1. 用 `X-Class-Token` 调用 `/classroom/join`；
2. 为当前浏览器保存独立学生会话；
3. 用 `X-Student-Token` 调用 `/chat/stream`；
4. 解析心跳、OpenAI SSE 数据块、错误事件和 `[DONE]`；
5. 学生会话失效时清理旧会话并重新加入一次。

课堂未开始或已经结束时，加入和对话会被拒绝；再次开始课堂后，原持久令牌恢复可用。主动“换一个链接”后，嵌入旧令牌的网页和已经换取的学生会话立即失效，需要重新复制代码。

## 由 EduGate 托管并发布网页

如果网页不需要部署到另一台 Web 服务器，推荐使用教师端“系统”页最后的“教学网页发布”：上传单个 HTML 或含 `index.html` 的 ZIP，控制页的学生链接和二维码会自动指向当前活动网页。同一网页可跨班级、课次和程序重启复用；切换活动网页不会轮换课堂令牌。

托管网页运行在隔离 iframe 中，不能直接读取 URL 中的课堂令牌。EduGate 会注入一个最小流式桥接：

```javascript
const request = EduGate.ask("请解释这个知识点", (delta) => {
  document.querySelector("#answer").textContent += delta;
});

const fullText = await request;
// 需要中止时：request.cancel();
```

包装页会代为执行 `/classroom/join` 和 `/chat/stream`。后端仍应用当前教师模型、提示词、知识库、课堂启停和学生限流。课堂未开始时，活动文档不会返回，Demo 测试页也无法加入课堂。上传结构、安全限制和多消息示例见 [教学网页发布](教学网页发布.md)。

## 在学生浏览器运行 Python

服务器不再执行学生代码。旧 `POST /run_python` 和 `/run_python/stream` 在通过课堂鉴权后返回 **410 Gone**，不要继续发送代码等待服务端执行；旧线程、队列、内存及解释器路径设置不再生效。

外部网页复用上面的 `edugate` 客户端：

```javascript
const controller = new AbortController();
const result = await edugate.runPython('print("你好，课堂")', {
  signal: controller.signal,
  onOutput(stream, text) {
    document.querySelector("#output").textContent += text;
  }
});
// result: stdout、stderr、exit_code、timed_out、duration_ms
// 需要停止时调用 controller.abort()；取消会抛出 AbortError。
```

EduGate 托管网页无需加载额外 SDK 或填写凭证：

```javascript
const task = EduGate.runPython('print(6 * 7)', (stream, text) => {
  document.querySelector("#output").textContent += text;
});
const result = await task;
// 需要停止时：task.cancel();
```

客户端先用学生会话读取 `GET /classroom/python-config`，在隔离 Worker 中执行，最后向 `POST /classroom/python-result` 上报原课次结果。运行环境和标准库从教师电脑的 `assets/vendor/pyodide/` 加载，无需外网；额外第三方 Python 包、任意外网请求和交互式 `input()` 暂未提供。每个页面同时执行一个任务，默认超时 3 秒，输出长度有限制。

如果课堂在执行期间结束或换链，上报会被拒绝，不会重新加入并把旧结果写入新课次。正常再次运行时 SDK 可重新取得学生会话。Python 输出是学生浏览器提供的数据，记录会明确标注，不能用作可信判分。教师开关控制服务接入与上报，不保证远程停止离线学生设备上的本地计算。

## 跨域设置

教学网页如果由 EduGate 自己提供，属于同源调用，无需 CORS。网页由其他服务器提供时，在“系统 → 高级设置 → 额外允许的跨域来源”中填写准确的 Origin，多个来源用英文逗号分隔，例如：

```text
http://172.16.100.20:8080,https://lms.school.example
```

Origin 只包含协议、主机和端口，不包含路径。保存后重启 EduGate 生效。不要为了省事在不可信网络中允许任意来源；CORS 只是浏览器来源控制，不能替代课堂令牌和学生会话鉴权。

## 安全范围

- 外部网页源码中的课堂令牌对页面访问者可见，这是学生入场凭证，不是教师或平台权限；EduGate 托管网页本身不接触该令牌。
- 每个浏览器换取独立学生会话并独立限流，课堂记录使用自动设备标签和请求 IP。
- 教师结束课堂会撤销全部学生会话；换链会同时永久淘汰旧课堂令牌。
- `PLATFORM_API_KEY` 可直接调用当前 AI 策略，不受学生会话约束，只能放在可信后端。
- 局域网默认是 HTTP，没有 TLS。只应在可信、隔离的教室网络使用，不要把端口映射到互联网。
