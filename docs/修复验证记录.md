## 兼容性与未覆盖范围

- 旧 `/run_python`、`/run_python/stream` 不再执行代码，鉴权后返回 410。外部网页迁移到 `EduGateClient.runPython()`；托管网页用 `EduGate.runPython()`。教师端 Python 线程/队列及原生解释器配置已移除，系统页改为执行位置。
- Python 结果明确是学生浏览器上报，不是可信判分；默认只包含离线运行环境及标准库，不提供 pip、任意外网请求、交互式输入或进程级内存硬配额。
- 课堂撤销阻止服务端旧请求及结果上报，不能保证远程停止离线学生设备上的本地计算，也不能追溯撤销模型供应商已接收的请求或计费。
- 本机 Chromium 和 EXE 已验证；尚未进行 iPad Safari、无开发环境的全新 Windows、多台真实局域网学生设备、真实模型供应商和整班长时间压力测试。这些属于部署验收，不能用自动化通过替代。
- 本地验证包不等于正式 Release；GitHub CI 和发布结果需针对实际提交另行确认。
